# மேல் பட்டை

உங்கள் திரையின் மேற்பகுதியில் உள்ள பட்டைதான் Omarchy பட்டை. இது பின்னால் பொருத்தப்பட்ட நிலைப் பட்டை அல்ல; இது Omarchy shell-இன் ஒரு பகுதி — மெனு, அறிவிப்புகள், OSD பாப்அப்கள் மற்றும் பூட்டுத் திரையையும் வரையும் ஒற்றை, நீண்ட நேரம் இயங்கும் Quickshell செயல்முறை. அதனால்தான் இது மற்ற எல்லாவற்றுடனும் மிகச் சரியாகத் தீம் செய்யப்படுகிறது, மேலும் புதிய செயலியை உருவாக்குவதற்குப் பதிலாக ஒரு பேனல் உடனடியாகத் திறக்கிறது.

டெஸ்க்டாப்பில் எப்போதும் திரையில் இருக்கும் ஒரே பகுதியும் இதுதான், எனவே அந்தச் சிறிய கிளிஃப்கள் எல்லாம் என்ன செய்கின்றன என்பதைத் தெரிந்து கொள்வது மதிப்புக்குரியது.

## இயல்பாக அதில் என்ன இருக்கும்

பட்டையில் மூன்று பிரிவுகள் உள்ளன. இடதுபுறம் Omarchy லோகோ (மெனு தொடக்கி) மற்றும் பணியிடக் குறிகாட்டிகள் அமர்ந்திருக்கும். நடுவில் நிலைக் குறிகாட்டிகள், கடிகாரம், Elsewhen (ஒரு உலகக் கடிகாரம்), வானிலை மற்றும் Omarchy புதுப்பிப்பு பேட்ஜ் கிடைக்கும். வலதுபுறம்: system tray, விசைப்பலகை தளவமைப்பு (ஒன்றுக்கு மேற்பட்ட தளவமைப்பு அல்லது உள்ளீட்டு முறை கட்டமைக்கப்பட்டிருக்கும்போது), agents, bluetooth, network, audio, display மற்றும் power.

அவற்றில் சில, சொல்வதற்கு ஏதாவது இருக்கும்போது மட்டுமே தோன்றும். ஒன்றுக்கு மேற்பட்ட தளவமைப்பு அல்லது உள்ளீட்டு முறையை நீங்கள் கட்டமைத்திருந்தால் மட்டுமே விசைப்பலகை தளவமைப்பு தோன்றும். Omarchy புதுப்பிப்பு காத்திருக்கும்போது மட்டுமே புதுப்பிப்பு பேட்ஜ் தோன்றும்.

## சுற்றி கிளிக் செய்தல்

கிட்டத்தட்ட ஒவ்வொரு விட்ஜெட்டும் இடது, வலது மற்றும் நடு கிளிக்கில் ஏதாவது செய்யும், மேலும் பல உருட்டலுக்கும் பதிலளிக்கும். மக்கள் தவறவிடும் பகுதி இதுதான் — வலது மற்றும் நடு பொத்தான்களில்தான் நல்ல விஷயங்கள் நிறைய மறைந்திருக்கும்.

## பேனல்கள்

பட்டை ஐகானைக் கிளிக் செய்தால் ஒரு பேனல் திறக்கும்; அது ஒரு டூல்டிப் அல்ல, ஸ்லைடர்கள், பட்டியல்கள் மற்றும் விசைப்பலகை வழிசெலுத்தலுடன் கூடிய முறையான பாப்அப். ஒவ்வொன்றுக்கும் ஒரு ஹாட்கீயும் உள்ளது, எனவே 16-பிக்சல் கிளிஃபை நீங்கள் ஒருபோதும் குறிவைக்க வேண்டியதில்லை:

| ஹாட்கீ | பேனல் |
| --- | --- |
| `Super + Ctrl + A` | Audio |
| `Super + Ctrl + N` | Network |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | Display |
| `Super + Ctrl + P` | Power |
| `Super + Ctrl + Alt + D` | காலண்டர் |
| `Super + Ctrl + Alt + E` | உலகக் கடிகாரம் |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | வலது பிரிவில் n-ஆவது பேனலை மாற்று |

பேனல்கள் வெறும் படிப்புகள் அல்ல. நீங்கள் உண்மையில் அந்தச் செயலைச் செய்யும் இடம் அவைதான்:

- **Audio**-வில் ஒரு முதன்மை ஒலியளவு ஸ்லைடர், ஒரு வெளியீட்டு-சாதனத் தேர்வி மற்றும் ஒரு செயலிக்கு-ஒன்று என்ற மிக்சர் உள்ளது, எனவே மற்ற எல்லாவற்றையும் தொடாமல் அந்த ஒரு உலாவி தாவலை மட்டும் குறைக்கலாம்.
- **Network** Wi-Fi-ஐ ஸ்கேன் செய்கிறது, சிக்னல் வலிமையைக் காட்டுகிறது, இணைக்கிறது, மேலும் ஒரு DNS வழங்குநரைத் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது.
- **Bluetooth** உங்கள் சாதனங்களை இணைப்பு/துண்டிப்பு மற்றும் பேட்டரி நிலைகளுடன் பட்டியலிடுகிறது.
- **Power** பேட்டரி புள்ளிவிவரங்களைக் காட்டுகிறது, power profile-களை மாற்றுகிறது (பேட்டரிக்கும் AC-க்கும் தனித்தனி தேர்வை அது நினைவில் வைத்திருக்கும்), மேலும் சில கணினித் தகவல்களை அச்சிடுகிறது.
- **Display**-யில் ஒரு பிரகாச ஸ்லைடர், உரை அளவு, மானிட்டர் அளவிடல் முன்னமைவுகள் மற்றும் — உங்களிடம் ஒன்றுக்கு மேற்பட்ட திரை இருக்கும்போது — மானிட்டருக்கு-ஒன்று என்ற கட்டுப்பாடுகள் உள்ளன. ஆழமான கதைக்கு [மானிட்டர்கள்](33-monitors.md) ஐப் பார்க்கவும்.
- **Clock** ISO வார எண்கள் மற்றும் மாதப் படியேற்றத்துடன் ஒரு மாதக் கட்டத்தைத் திறக்கிறது.
- **World clock** ஒவ்வொரு நகரத்திற்கும் ஒரு வரிசையை வைத்திருக்கிறது, அதன் வானிலை மற்றும் அதன் நாள் எப்படி போய்க்கொண்டிருக்கிறது என்பதுடன். தேடல் நேர மண்டலங்களைப் போலவே நகரங்களையும் கண்டுபிடிக்கிறது, எனவே Fort Lauderdale என்பது Fort Lauderdale தான், New York அல்ல. மேலே உள்ள வரி தவறான நகரத்தைப் பெயரிட்டால், அதைக் கிளிக் செய்து நீங்கள் எங்கிருக்கிறீர்கள் என்று சொல்லவும்; வேறு நேர மண்டலத்தில் உள்ள ஒரு இடத்தைத் தேர்ந்தெடுத்தால் கணினிக் கடிகாரமும் அங்கே நகரும், நீங்கள் பயணம் செய்யும்போது இது வசதியாக இருக்கும். ஒரு நகரத்தின் மீது ஹோவர் செய்து, அங்கு யார் வசிக்கிறார்கள் என்று சொல்ல person பொத்தானைக் கிளிக் செய்யவும் — எளிய பெயர்கள், அல்லது அவர்களின் முகங்களையும் கொண்டுவர `@` GitHub கைப்பிடிகள்.

ஒவ்வொரு பேனலும் மவுஸைப் போலவே விசைப்பலகையையும் ஏற்கிறது: அம்புக்குறிகள் நகரும், Return செயல்படுத்தும், Tab அருகிலுள்ள பேனலுக்குப் படியேறும், Escape மூடும்.

`Super + Ctrl + 1-9` வலது பிரிவில் பேனல்களை இடமிருந்து வலமாக எண்ணுகிறது, tray-க்கு சொந்தமாகப் பேனல் இல்லை என்பதால் அதைத் தவிர்த்து. எனவே அந்த எண் நீங்கள் சுட்டிக்காட்டும் ஐகானுடன் பொருந்தும்.

### Tailscale and Dropbox

**Install → Service**-இலிருந்து பொருந்தும் சேவையை நீங்கள் நிறுவிய பிறகு மட்டுமே இன்னும் இரண்டு விட்ஜெட்கள் பட்டையில் தோன்றும், மேலும் அவை நிலையைப் புகாரளிப்பதை விட அதிகம் செய்வதால் இரண்டையும் பற்றித் தெரிந்து கொள்வது மதிப்புக்குரியது.

**Tailscale** பேனல் tailnet-ஐ இணைக்கிறது மற்றும் துண்டிக்கிறது, கணக்குகளுக்கு இடையே மாறுகிறது, மேலும் ஒரு exit node-ஐத் தேர்ந்தெடுக்கிறது (உங்கள் சொந்த இயந்திரங்கள் மற்றும் Mullvad பகுதிகள் இரண்டும் அந்தப் பட்டியலில் தோன்றும்). இது உங்கள் இயந்திரங்களையும் உலாவுகிறது — மேலும் ஒன்று தேர்ந்தெடுக்கப்பட்டிருக்கும்போது, `s` Taildrop வழியாக அதற்குக் கோப்புகளை அனுப்புகிறது, இது உங்கள் தொலைபேசிக்கு அல்லது மற்றொரு மடிக்கணினிக்கு ஒரு கோப்பை நகர்த்துவதற்கான வேகமான வழி. `c` இயந்திரத்தின் IP-ஐ நகலெடுக்கிறது, `n` அதன் பெயரை, `d` அதன் முழு DNS பெயரை. நீங்கள் கிளிக் செய்ய விரும்பினால், ஒவ்வொரு இயந்திர வரிசையிலும் ஒரு அனுப்பு பொத்தானும் உள்ளது. டெர்மினலில் இருந்து அதே விஷயம் `omarchy tailscale send <machine> [file...]`.

**Dropbox** பேனல் உள்நுழைவைக் கையாளுகிறது, நீங்கள் எவ்வளவு சேமிப்பகத்தைப் பயன்படுத்தியுள்ளீர்கள் என்பதைக் காட்டுகிறது, மேலும் சமீபத்தில் ஒத்திசைக்கப்பட்ட கோப்புகளைப் பட்டியலிடுகிறது.

ஏதாவது ஒரு சேவையை அகற்றினால் அதன் விட்ஜெட் பட்டையிலிருந்து மீண்டும் நீங்கிவிடும்.

## குறிகாட்டிகள்

நடுவில் உள்ள சிறிய தொகுப்புதான் குறிகாட்டிகள் விட்ஜெட். நீங்கள் இயக்கியுள்ள முறைகளுக்கான நிலை கிளிஃப்கள் இவை: தொந்தரவு செய்ய வேண்டாம், இரவு ஒளி, வரிசையில் உள்ள [நினைவூட்டல்](09-reminders.md), செயலில் உள்ள திரைப் பதிவு மற்றும் விழித்திரு, கூடவே கடவுச்சொல் இல்லாத sudo இயக்கத்தில் இருக்கும்போது அல்லது யாராவது தொலை அமர்வுடன் இணைக்கப்பட்டிருக்கும்போது எச்சரிக்கைகள். அந்த முறை செயலில் இருக்கும்போது அவை ஒளிர்கின்றன, மற்றபடி வழியில் இல்லாமல் இருக்கின்றன — செயலற்றவை அமர்ந்திருக்கும் இடத்தில், அவற்றுக்குப் பக்கத்திலேயே ஹோவர் செய்து அவற்றை எட்டிப் பார்க்கவும். ஒரு குறிகாட்டியைக் கிளிக் செய்தால் அந்த முறை மாறும். இன்னொன்று நிலை மட்டுமே: gliff வழியாக யாராவது இந்த இயந்திரத்துடன் இணைக்கப்பட்டிருக்கும்போது தொலை அமர்வு சிவப்பாக ஒளிரும்.

அவை எப்போதும் தெரிய வேண்டும் என்று நீங்கள் விரும்பினால், விட்ஜெட்டில் `alwaysShow`-வை `true` என அமைக்கவும். அவற்றில் சிலவற்றைப் பற்றி மட்டுமே நீங்கள் கவலைப்பட்டால், நீங்கள் விரும்புவதை `items`-இல் பட்டியலிடவும்: `["Dnd", "Reminder", "NightLight"]`. நீங்கள் ஒன்றுக்கு மேற்பட்ட குறிகாட்டிகள் விட்ஜெட்டை வைத்திருக்கலாம், எனவே வெவ்வேறு பிரிவுகள் வெவ்வேறு துணைத்தொகுப்புகளைக் காட்டலாம்.

## பட்டையை மறுஒழுங்கு செய்தல்

பட்டை தன்னைத்தானே கட்டமைத்துக் கொள்கிறது. விஷயங்களை நகர்த்த நீங்கள் ஒரு கான்ஃபிக் கோப்பைத் திறக்க வேண்டியதில்லை.

நடுவைச் சுற்றியுள்ள பட்டையின் காலி இடத்தைப் பிடித்து மற்றொரு திரை விளிம்பை நோக்கி இழுக்கவும், பட்டை அங்கே நகரும் — இடது, வலது, மேல் அல்லது கீழ் எல்லாம் வேலை செய்யும், மேலும் ஒவ்வொரு விட்ஜெட்டும் தகவமைத்துக் கொள்ளும் (செங்குத்துப் பட்டைகள் சுருக்கமான ஐகான்-மட்டும் வடிவங்களுக்குத் திரும்பும்). கிளிக்-செய்து-பிடித்தாலும் அதே இழுத்தல் தொடங்கும். அதே காலி இடத்தில் இரட்டை-இடது-கிளிக் செய்தால் பட்டையின் பின்னணி தெளிவிலிருந்து கண்ணாடி போன்றதாக, பின்னர் ஒளிபுகாததாகச் சுழலும். மேலும் எந்த விட்ஜெட்டையும் இழுத்து அதை மறுஒழுங்கு செய்யவும் அல்லது மற்றொரு பிரிவுக்குள் எறியவும்; மற்ற விட்ஜெட்கள் அது விழப்போகும் இடத்தில் இடம் உண்டாக்க விலகி நகரும்.

பட்டையின் நடுப்பகுதி ஒரு பெட்டி: அதில் உள்ளது எதுவாக இருந்தாலும் ஒரே குழுவாக மையப்படுத்தப்பட்டிருக்கும், அதன் இருபுறமும் உள்ள விட்ஜெட்கள் அதன் விளிம்புகளில் தொங்கும். நீங்கள் ஒரு விட்ஜெட்டை இழுக்கும்போது பெட்டி ஒரு வெளிக்கோடாகக் காட்டப்படும், அல்லது அது காலியாக இருக்கும்போது பட்டையின் குறுக்கே ஒரு கோடாகக் காட்டப்படும், மேலும் நீங்கள் அதற்குள்ளோ அதன் பக்கத்திலோ விடலாம். ஒரு விடுதல் பெட்டியில் விழும்போது, பெட்டி அந்த விட்ஜெட்டை உள்ளே எடுத்துக்கொள்ள வளரும்.

நீங்கள் அருகில் வைத்திருக்க விரும்பும் ஆனால் எப்போதும் பார்வையில் இருக்க விரும்பாத ஒரு விட்ஜெட் tray-இன் டிராயருக்குள் போகலாம்: அதை tray-இன் மீது இழுக்கவும், டிராயர் அதை உள்ளே எடுக்கத் திறக்கும். அது செயலி ஐகான்களுக்குப் பிறகு அங்கே அமர்ந்திருக்கும், டிராயர் தோன்றும் போதெல்லாம் தோன்றும், மேலும் அதன் பேனல் மேலே இருக்கும்போது அதன் டிராயரைத் திறந்தே வைத்திருக்கும். அதை மீண்டும் பட்டையின் மீது இழுத்து வெளியே கொண்டுவந்து திரும்ப வைக்கவும்.

மெனுவிலிருந்து தேர்ந்தெடுக்க விரும்பினால், **Appearance → Menu Bar**-இல் நிலை உள்ளது, மேலும் **Bar Background** பட்டை எப்படி வரையப்படுகிறது என்பதைத் தேர்ந்தெடுக்கிறது: **Opaque Bar**, **Glassy Bar** (ஊடுருவிப் பார்க்கக்கூடியது, அதன் பின்னால் உள்ளது மங்கலாக்கப்பட்டிருக்கும்), அல்லது **Clear Bar**.

அதே விஷயங்களுக்குக் கட்டளைகளும் உள்ளன, [dotfiles](31-dotfiles.md) அமைப்புக்கு நீங்கள் விரும்புவது அதுதான்:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ஒரு விட்ஜெட்டை முழுவதுமாகச் சேர்க்க அல்லது அகற்ற, plugin கட்டளைகளைப் பயன்படுத்தவும். `omarchy plugin list` shell-க்குத் தெரிந்த ஒவ்வொரு விட்ஜெட்டையும் அதன் id-யுடன் அச்சிடுகிறது, பின்னர்:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## பட்டையை மறைத்தல்

`Super + Shift + Space` shell-ஐ அழிக்காமல் பட்டையை அணைத்து மீண்டும் இயக்குகிறது — பேனல்களும் ஹாட்கீகளும் தொடர்ந்து வேலை செய்யும், நீங்கள் பிக்சல்களை மட்டும் திரும்பப் பெறுவீர்கள். இது மெனுவில் **Appearance → Menu Bar → Hide Bar**-இன் கீழும் உள்ளது.

## கான்ஃபிக் கோப்பு

எல்லாமே `~/.config/omarchy/shell.json`-இல், `bar` விசையின் கீழ் சேமிக்கப்படுகிறது. இதோ ஒரு சுருக்கப்பட்ட பதிப்பு:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ஒவ்வொரு விட்ஜெட்டும் ஐந்து தளவமைப்பு வரிசைகளில் ஒன்றில் ஒரு உள்ளீடு, மேலும் அதன் அமைப்புகள் அந்த உள்ளீட்டிலேயே உள்ளமைந்திருக்கும் — தனி அமைப்புகள் கோப்பு இல்லை, `config` துணை-பொருளும் இல்லை. கடிகாரத்தின் `format`, `formatAlt` (வலது-கிளிக் எதற்குச் சுழல்கிறதோ அது), மற்றும் `verticalFormat` எல்லாம் `{ "id": "omarchy.clock" }`-இலேயே அங்கேயே வாழ்கின்றன.

`center` என்பது பட்டையின் நடுவில் உள்ள பெட்டி: அதில் உள்ள எல்லாமே ஒரே குழுவாகத் திரையில் மையப்படுத்தப்படும். `centerBegin` மற்றும் `centerEnd` பெட்டியின் இருபுறமும் தொங்கும், வானிலையும் புதுப்பிப்பு பேட்ஜும் வந்து போகும்போதும் கடிகாரம் சரியாக நடுவில் இருப்பது இப்படித்தான். `center`-இல் ஒன்றுக்கு மேற்பட்ட விட்ஜெட்டை வைக்கவும், அவை ஒன்றாக மையப்படுத்தப்படும்; அதைக் காலியாக விடவும், `centerBegin` மற்றும் `centerEnd` பட்டையின் நடுவில் சந்திக்கும்.

உள்வாங்கிக் கொள்ள வேண்டிய ஒரு விதி: **உங்களுக்கென சொந்த `shell.json` இருந்துவிட்டால், அதுதான் அதிகாரப்பூர்வமானது**. நீங்கள் எதையும் தனிப்பயனாக்கும் வரை, shell Omarchy-இன் இயல்புநிலைக் கோப்பைப் படிக்கிறது. நீங்கள் ஒரு விட்ஜெட்டை இழுத்த கணம், `omarchy bar`-ஐ இயக்கிய கணம், அல்லது கோப்பை நீங்களே திருத்திய கணம், அது உங்களுடையது — ஆழமான இணைப்பு எதுவும் இல்லை, எனவே எதிர்கால Omarchy வெளியீடுகளில் புதிய இயல்புநிலை விட்ஜெட்கள் உங்கள் பட்டையில் தானாகத் தோன்றாது. சுத்தமான தொடக்கம் வேண்டும்போதெல்லாம் `omarchy bar defaults` வழங்கப்பட்ட தளவமைப்பைத் திரும்ப வைக்கிறது.

அதே கோப்பு உங்கள் செயலற்ற நேரங்களையும் மேல் மட்டத்தில், `bar` விசைக்கு வெளியே வைத்திருக்கிறது: `idle.screensaver` மற்றும் `idle.lock`, இரண்டும் நீங்கள் செயலற்றுப் போனதிலிருந்து வினாடிகளில். எனவே இயல்புநிலை திரைச்சேமிப்பான் 150 வினாடிகளில் தொடங்கும், பூட்டு 300-இல்.
