# 頂部列

螢幕頂端的那條橫列就是 Omarchy 列。它不是外加的狀態列，而是 Omarchy shell 的一部分；Omarchy shell 是單一且長時間執行的 Quickshell 程序，同時也負責繪製選單、通知、OSD 彈出視窗和鎖定畫面。這就是為什麼它能和其它所有東西完美地套用同一個主題，也是為什麼面板會立即開啟，而不是啟動一個新的應用程式。

它也是桌面上唯一永遠顯示在螢幕上的部分，所以值得了解一下那些小圖示到底能做什麼。

## 預設顯示哪些東西

這條列分成三個區塊。左側是 Omarchy logo（選單啟動器）和工作區指示器。中央有狀態指示器、時鐘、Elsewhen（世界時鐘）、天氣，以及 Omarchy 更新徽章。右側則有：系統匣、鍵盤配置（當你設定了多於一種配置或輸入法時）、Agents、藍牙、網路、音訊、顯示器和電源。

其中有幾項只有在有話要說時才會出現。鍵盤配置只有在你設定了多於一種配置或輸入法時才會出現。更新徽章只有在有 Omarchy 更新正在等待時才會出現。

## 面板

點一下列上的圖示會開啟一個面板，那是一個正經的彈出視窗，有滑桿、清單和鍵盤導覽，而不是一個工具提示。每個面板也都有一個快速鍵，所以你永遠不必去瞄準一個 16 像素的小圖示：

| 快速鍵 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音訊 |
| `Super + Ctrl + N` | 網路 |
| `Super + Ctrl + B` | 藍牙 |
| `Super + Ctrl + D` | 顯示器 |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | 行事曆 |
| `Super + Ctrl + Alt + E` | 世界時鐘 |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | 切換右側區塊中的第 n 個面板 |

這些面板不是只用來看的。它們是你真正動手做事的地方：

- **音訊**有一個主音量滑桿、一個輸出裝置選擇器，以及一個逐應用程式混音器，所以你可以把那一個瀏覽器分頁的聲音調小，而不碰其它任何東西。
- **網路**會掃描 Wi-Fi、顯示訊號強度、進行連線，並讓你選擇一個 DNS 提供者。
- **藍牙**會列出你的裝置，附有連線／中斷連線和電池電量。
- **電源**會顯示電池統計資料、切換電源設定檔（它會分別記住電池和 AC 時的選擇），並印出一些系統資訊。
- **顯示器**帶有亮度滑桿、文字大小、螢幕縮放預設值，而且——當你有多於一個螢幕時——還有逐螢幕控制項。更深入的故事請見[顯示器](33-monitors.md)。
- **時鐘**會開啟一個月份格子，附有 ISO 週數和月份步進。
- **世界時鐘**為每個城市保留一列，附有它的天氣以及它那一天過得如何。搜尋能找到城鎮，也能找到時區，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果頂端那一行說的城市不對，點它並告訴它你在哪裡；選一個位於另一個時區的地方，系統時鐘也會跟著移到那裡，旅行時很方便。將滑鼠懸停在一個城市上，點一下人物按鈕，說出住在那裡的人是誰——可以使用普通姓名，或使用 `@` GitHub 帳號，把他們的臉也一起帶進來。

每個面板都能用鍵盤，也能用滑鼠：方向鍵移動，Return 啟用，Tab 步進到相鄰的面板，Escape 關閉。

`Super + Ctrl + 1-9` 會從左到右計算右側區塊中的面板，並跳過系統匣，因為它沒有自己的面板。所以那個數字會和你會指到的圖示相符。

### Tailscale 和 Dropbox

還有兩個元件只有在你從 **安裝 → 服務** 安裝了對應的服務後，才會出現在列上，而且兩者都值得認識，因為它們做的事不只是報告狀態。

**Tailscale** 面板會連線和中斷 tailnet、在帳號之間切換，並選擇一個 exit node（你自己的機器和 Mullvad 地區都會出現在那份清單裡）。它也會瀏覽你的機器——而且在選取一台機器後，`s` 會透過 Taildrop 把檔案傳送給它，這是把檔案移到你的手機或另一台筆記型電腦最快的方式。`c` 複製機器的 IP，`n` 複製它的名稱，`d` 複製它的完整 DNS 名稱。每個機器列上也有一個傳送按鈕，如果你寧願用點的。在終端機裡做同一件事是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板處理登入、顯示你已用了多少儲存空間，並列出最近同步的檔案。

移除任何一個服務，都會把它的元件從列上拿掉。

## 指示器

中央的那一小簇是指示器元件。這些是你已開啟的模式的狀態圖示：勿擾、夜間光、已排入佇列的[提醒](09-reminders.md)、進行中的螢幕錄影，以及保持喚醒，此外還有當無密碼 sudo 開啟或有人連線到一個遠端工作階段時的警告。它們在模式啟用時亮起，否則就待在一旁不礙事——將滑鼠懸停在它們旁邊、也就是未啟用的那些本來會待的位置，就能偷看那些未啟用的。點一下一個指示器會切換該模式。還有一個只是狀態：當有人透過 gliff 連線到這台機器時，遠端工作階段會亮起紅色。

如果你寧願它們永遠可見，把該元件上的 `alwaysShow` 設為 `true`。如果你只在乎其中幾項，把你想要的那些列在 `items` 裡：`["Dnd", "Reminder", "NightLight"]`。你可以有多於一個指示器元件，所以不同區塊可以顯示不同的子集。

## 重新排列這條列

這條列會自己設定自己。你不必打開一個設定檔來移動東西。

抓住中央周圍一塊空白處，把它拖向另一個螢幕邊緣，這條列就會移到那裡——左、右、上或下都可以，而且每個元件都會適應（垂直列會退回成精簡的僅圖示形式）。點按並按住也會啟動同樣的拖曳。在同樣的空白處連按兩下左鍵，會讓列的背景從透明循環切換到玻璃質感到不透明。而拖曳任何元件可以重新排序它，或把它丟進另一個區塊；其它元件會滑開，在它將落下的位置騰出空間。

這條列的中間是一個方框：裡面的任何東西都會作為一個群組保持置中，它兩側的元件則懸掛在它的邊緣。當你拖曳一個元件時，這個方框會顯示為一個外框，或者在它為空時顯示為橫跨這條列的一條線，你可以把它放到裡面或它旁邊。當一次放置會落入方框時，方框會長大，把該元件收進去。

一個你想留著但不想永遠看見的元件可以放進系統匣的抽屜裡：把它拖到系統匣上，抽屜就會打開來接收它。它會待在那裡，排在應用程式圖示之後，每當抽屜出現時就會現身，而且在它的面板開啟時保持抽屜打開。把它拖回列上就能放回去。

如果你寧願從選單裡選，**外觀 → 選單列**裡有位置，而 **列背景**挑選這條列如何繪製：**不透明列**、**玻璃質感列**（透明，背後的東西會被模糊），或**透明列**。

同樣的事也有指令，這正是你為 [dotfiles](31-dotfiles.md) 設定想要的：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要完整新增或移除一個元件，使用外掛指令。`omarchy plugin list` 會印出 shell 知道的每個元件及其 id，然後：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隱藏這條列

`Super + Shift + Space` 會把這條列關掉再開啟，而不會殺掉 shell——面板和快速鍵繼續運作，你只是把像素拿回來。它也在選單裡的 **外觀 → 選單列 → 隱藏列**底下。

## 設定檔

這一切都儲存在 `~/.config/omarchy/shell.json` 裡，位於 `bar` 鍵底下。這是一個修剪過的版本：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每個元件都是五個 layout 陣列其中之一的一個項目，而且它的設定就內嵌在該項目上——沒有分開的設定檔，也沒有 `config` 子物件。時鐘的 `format`、`formatAlt`（右鍵循環切換到的那個）和 `verticalFormat` 全都直接住在 `{ "id": "omarchy.clock" }` 上。

`center` 是這條列中間的方框：裡面的所有東西都會作為一個群組在螢幕上置中。`centerBegin` 和 `centerEnd` 懸掛在方框的任一側，這就是時鐘即使在天氣和更新徽章來來去去時仍能保持正中央的方式。把多於一個元件放進 `center`，它們會一起置中；讓它保持為空，`centerBegin` 和 `centerEnd` 就會在這條列的中間相遇。

有一條規則值得內化：**一旦你有了自己的 `shell.json`，它就是權威**。在你自訂任何東西之前，shell 讀取的是 Omarchy 的預設檔案。你拖曳一個元件、執行 `omarchy bar`，或自己編輯檔案的那一刻起，它就歸你所有了——沒有深層合併，所以未來 Omarchy 版本中的新預設元件不會自動出現在你的列上。`omarchy bar defaults` 會在你想要一張乾淨的白紙時，隨時把出廠的配置放回去。

同一個檔案也在頂層、`bar` 鍵之外，保存著你的閒置計時：`idle.screensaver` 和 `idle.lock`，兩者都是自你閒置以來經過的秒數。所以預設的螢幕保護程式會在 150 秒時啟動，鎖定則在 300 秒時。
