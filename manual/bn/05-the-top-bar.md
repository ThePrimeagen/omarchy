# উপরের বার

আপনার স্ক্রিনের উপরের দিক ধরে থাকা স্ট্রিপটাই হলো Omarchy বার। এটি কোনো বাইরে থেকে জুড়ে দেওয়া স্ট্যাটাস বার নয়, বরং এটি Omarchy শেলের অংশ, সেই একটিমাত্র দীর্ঘস্থায়ী Quickshell প্রসেসের, যা মেনু, নোটিফিকেশন, OSD পপআপ এবং লক স্ক্রিনও আঁকে। এ কারণেই এটি অন্য সবকিছুর সঙ্গে নিখুঁতভাবে থিম মিলিয়ে চলে এবং এ কারণেই একটি নতুন অ্যাপ চালু করার বদলে একটি প্যানেল তৎক্ষণাৎ খুলে যায়।

এটি ডেস্কটপের সেই একটিই অংশ যা সবসময় স্ক্রিনে থাকে, তাই ওই ছোট ছোট গ্লিফগুলো কী করে তা জেনে রাখা মূল্যবান।

## ডিফল্টভাবে এতে যা যা থাকে

বারটির তিনটি অংশ রয়েছে। বাম দিকে থাকে Omarchy লোগো (মেনু লঞ্চার) এবং ওয়ার্কস্পেস নির্দেশকগুলো। মাঝখানে আপনি পাবেন স্ট্যাটাস নির্দেশকগুলো, ঘড়ি, Elsewhen (একটি বিশ্ব ঘড়ি), আবহাওয়া এবং একটি Omarchy আপডেট ব্যাজ। ডান দিকে: সিস্টেম ট্রে, কীবোর্ড লেআউট (যখন একাধিক লেআউট বা ইনপুট পদ্ধতি কনফিগার করা থাকে), agents, bluetooth, network, audio, display এবং power।

এর মধ্যে কয়েকটি কেবল তখনই দেখা দেয় যখন তাদের কিছু বলার থাকে। কীবোর্ড লেআউট কেবল তখনই দেখা দেয় যদি আপনি একাধিক লেআউট বা ইনপুট পদ্ধতি কনফিগার করে থাকেন। আপডেট ব্যাজ কেবল তখনই দেখা দেয় যখন একটি Omarchy আপডেট অপেক্ষা করছে।

## এদিক-ওদিক ক্লিক করা

## প্যানেলগুলো

একটি বার আইকনে ক্লিক করলে একটি প্যানেল খোলে, যা টুলটিপের বদলে স্লাইডার, তালিকা এবং কীবোর্ড নেভিগেশনসহ একটি যথাযথ পপআপ। প্রতিটির একটি হটকিও রয়েছে, তাই আপনাকে কখনোই একটি 16-পিক্সেল গ্লিফের দিকে তাক করতে হয় না:

| হটকি | প্যানেল |
| --- | --- |
| `Super + Ctrl + A` | অডিও |
| `Super + Ctrl + N` | নেটওয়ার্ক |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ডিসপ্লে |
| `Super + Ctrl + P` | পাওয়ার |
| `Super + Ctrl + Alt + D` | ক্যালেন্ডার |
| `Super + Ctrl + Alt + E` | বিশ্ব ঘড়ি |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | ডান অংশের n-তম প্যানেল চালু/বন্ধ করুন |

প্যানেলগুলো কেবল তথ্য দেখানোর জায়গা নয়। এখানেই আপনি আসল কাজটি করেন:

- **Audio**-তে একটি মাস্টার ভলিউম স্লাইডার, একটি আউটপুট-ডিভাইস পিকার এবং একটি প্রতি-অ্যাপ মিক্সার রয়েছে, তাই অন্য সবকিছু না ছুঁয়েই আপনি ওই একটি ব্রাউজার ট্যাবের শব্দ কমাতে পারেন।
- **Network** Wi-Fi খোঁজে, সিগন্যালের শক্তি দেখায়, সংযোগ করে এবং আপনাকে একটি DNS প্রদানকারী বেছে নিতে দেয়।
- **Bluetooth** সংযোগ/সংযোগ বিচ্ছিন্ন এবং ব্যাটারির স্তরসহ আপনার ডিভাইসগুলোর তালিকা দেখায়।
- **Power** ব্যাটারির পরিসংখ্যান দেখায়, পাওয়ার প্রোফাইল বদলায় (এটি ব্যাটারি এবং AC-এর জন্য আলাদা পছন্দ মনে রাখে) এবং কিছু সিস্টেম তথ্য ছাপায়।
- **Display**-তে একটি উজ্জ্বলতা স্লাইডার, লেখার আকার, মনিটর স্কেলিং প্রিসেট এবং — যখন আপনার একাধিক স্ক্রিন থাকে — প্রতি-মনিটরের নিয়ন্ত্রণ থাকে। আরও গভীর গল্পের জন্য [মনিটর](33-monitors.md) দেখুন।
- **Clock** ISO সপ্তাহ নম্বর এবং মাস বদলানোর সুবিধাসহ একটি মাসের গ্রিড খোলে।
- **World clock** প্রতি শহরের জন্য একটি সারি রাখে, তার আবহাওয়া এবং তার দিন কেমন যাচ্ছে তা সহ। অনুসন্ধান টাইম জোনের পাশাপাশি শহরও খুঁজে পায়, তাই Fort Lauderdale হলো Fort Lauderdale, New York নয়। উপরের লাইনটিতে যদি ভুল শহরের নাম থাকে, তাতে ক্লিক করুন এবং বলুন আপনি কোথায় আছেন; অন্য টাইম জোনে কোথাও বেছে নিলে সিস্টেম ঘড়িও সেখানে সরে যায়, যা ভ্রমণের সময় সুবিধাজনক। একটি শহরের উপর হোভার করুন এবং সেখানে কে থাকে তা বলতে ব্যক্তি বোতামে ক্লিক করুন — সাধারণ নাম, অথবা তাদের মুখ ছবিসহ আনতে `@` GitHub হ্যান্ডেল।

প্রতিটি প্যানেল মাউসের পাশাপাশি কীবোর্ডও নেয়: তীর চিহ্নগুলো ঘোরে, Return সক্রিয় করে, Tab পাশের প্যানেলে যায় এবং Escape বন্ধ করে।

`Super + Ctrl + 1-9` ডান অংশে প্যানেলগুলোকে বাম থেকে ডানে গোনে, ট্রেকে বাদ দিয়ে কারণ এর নিজের কোনো প্যানেল নেই। তাই নম্বরটি সেই আইকনের সঙ্গে মিলে যায় যার দিকে আপনি ইশারা করতেন।

### Tailscale এবং Dropbox

আপনি **Install → Service** থেকে মিলে যাওয়া সেবাটি ইনস্টল করলেই আরও দুটি উইজেট বারে দেখা দেয়, এবং দুটোই জেনে রাখা মূল্যবান কারণ তারা স্ট্যাটাস জানানোর চেয়ে বেশি কিছু করে।

**Tailscale** প্যানেল টেইলনেট সংযোগ করে এবং সংযোগ বিচ্ছিন্ন করে, অ্যাকাউন্টগুলোর মধ্যে বদলায় এবং একটি এক্সিট নোড বেছে নেয় (আপনার নিজের মেশিন এবং Mullvad অঞ্চল দুটোই ওই তালিকায় দেখা যায়)। এটি আপনার মেশিনগুলোও ব্রাউজ করে — এবং একটি নির্বাচন করা থাকলে, `s` Taildrop-এর মাধ্যমে এতে ফাইল পাঠায়, যা আপনার ফোন বা অন্য ল্যাপটপে একটি ফাইল সরানোর দ্রুততম উপায়। `c` মেশিনের IP অনুলিপি করে, `n` তার নাম এবং `d` তার পূর্ণ DNS নাম অনুলিপি করে। প্রতিটি মেশিনের সারিতে একটি পাঠানোর বোতামও রয়েছে, যদি আপনি বরং ক্লিক করতে চান। টার্মিনাল থেকে একই কাজ হলো `omarchy tailscale send <machine> [file...]`।

**Dropbox** প্যানেল লগইন পরিচালনা করে, আপনি কতটা স্টোরেজ ব্যবহার করেছেন তা দেখায় এবং সম্প্রতি সিঙ্ক করা ফাইলগুলোর তালিকা দেয়।

যেকোনো একটি সেবা সরিয়ে ফেললে তার উইজেট বার থেকে আবার চলে যায়।

## নির্দেশকগুলো

মাঝখানের ছোট গুচ্ছটিই হলো নির্দেশক উইজেট। এগুলো আপনার চালু করা মোডগুলোর জন্য স্ট্যাটাস গ্লিফ: বিরক্ত করবেন না, রাতের আলো, সারিতে থাকা একটি [অনুস্মারক](09-reminders.md), একটি সক্রিয় স্ক্রিন রেকর্ডিং এবং জেগে থাকুন, পাশাপাশি পাসওয়ার্ডবিহীন sudo চালু থাকলে অথবা কেউ একটি রিমোট সেশনে সংযুক্ত থাকলে সতর্কতা। মোড সক্রিয় থাকলে এগুলো জ্বলে ওঠে এবং অন্যথায় পথ থেকে দূরে থাকে — ওগুলো দেখতে তাদের ঠিক পাশে হোভার করুন, যেখানে নিষ্ক্রিয়গুলো বসত। একটি নির্দেশকে ক্লিক করলে ওই মোড চালু/বন্ধ হয়। আরও একটি কেবল স্ট্যাটাসের জন্য: gliff-এর মাধ্যমে কেউ এই মেশিনে সংযুক্ত থাকলে একটি রিমোট সেশন লাল হয়ে জ্বলে।

আপনি যদি বরং সেগুলো সবসময় দৃশ্যমান রাখতে চান, উইজেটে `alwaysShow`-কে `true`-তে সেট করুন। এবং আপনি যদি কেবল সেগুলোর কয়েকটির ব্যাপারে আগ্রহী হন, `items`-এ যেগুলো চান সেগুলোর তালিকা দিন: `["Dnd", "Reminder", "NightLight"]`। আপনার একাধিক নির্দেশক উইজেট থাকতে পারে, তাই বিভিন্ন অংশ বিভিন্ন উপসেট দেখাতে পারে।

## বারটি পুনরায় সাজানো

বারটি নিজেকে নিজেই কনফিগার করে। জিনিসপত্র সরাতে আপনাকে কোনো কনফিগ ফাইল খুলতে হয় না।

মাঝখানের চারপাশে বারের একটি খালি জায়গা ধরুন এবং এটিকে অন্য স্ক্রিনের ধারের দিকে টানুন, এবং বারটি সেখানে চলে যায় — বাম, ডান, উপরে বা নিচে সবই কাজ করে, এবং প্রতিটি উইজেট মানিয়ে নেয় (উল্লম্ব বারগুলো সংক্ষিপ্ত কেবল-আইকন আকারে ফিরে যায়)। ক্লিক-এবং-ধরে রাখলে একই টানা শুরু হয়। বার ব্যাকগ্রাউন্ডকে পরিষ্কার থেকে কাচের মতো থেকে অস্বচ্ছতে ঘোরাতে সেই একই খালি জায়গায় ডাবল-বাম-ক্লিক করুন। এবং পুনরায় সাজাতে বা অন্য অংশে ছুড়ে দিতে যেকোনো উইজেট টানুন; অন্য উইজেটগুলো সরে গিয়ে যেখানে এটি পড়বে সেখানে জায়গা করে দেয়।

বারের মাঝখানটি একটি বাক্স: এর ভিতরে যা কিছু আছে তা একটি গোষ্ঠী হিসাবে কেন্দ্রে থাকে, এবং এর দুই পাশের উইজেটগুলো এর ধার থেকে ঝুলে থাকে। আপনি একটি উইজেট টানার সময় বাক্সটি একটি রূপরেখা হিসাবে দেখা যায়, অথবা খালি থাকলে বারের উপর দিয়ে একটি লাইন হিসাবে, এবং আপনি এর ভিতরে বা এর পাশে ছাড়তে পারেন। একটি ছাড়া যখন বাক্সে পড়তে যায়, তখন বাক্সটি উইজেটটিকে নেওয়ার জন্য বড় হয়।

আপনি কাছাকাছি চান কিন্তু সবসময় দৃশ্যে নয় এমন একটি উইজেট ট্রের ড্রয়ারে যেতে পারে: এটিকে ট্রেতে টানুন, এবং ড্রয়ারটি এটিকে নিতে খুলে যায়। এটি অ্যাপ আইকনগুলোর পরে সেখানে বসে, ড্রয়ার যখনই দেখা দেয় তখনই দেখা দেয়, এবং এর প্যানেল খোলা থাকার সময় এর ড্রয়ার খোলা রাখে। এটিকে ফিরিয়ে আনতে বারটিতে আবার টেনে বাইরে আনুন।

আপনি যদি বরং একটি মেনু থেকে বেছে নিতে চান, **Appearance → Menu Bar**-এ অবস্থান রয়েছে, এবং **Bar Background** বেছে নেয় বারটি কীভাবে আঁকা হবে: **Opaque Bar**, **Glassy Bar** (স্বচ্ছ, এর পিছনে যা আছে তা ঝাপসা করা), অথবা **Clear Bar**।

একই জিনিসগুলোর কমান্ডও রয়েছে, যা আপনি একটি [dotfiles](31-dotfiles.md) সেটআপের জন্য চান:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

সম্পূর্ণরূপে একটি উইজেট যোগ বা সরাতে, প্লাগইন কমান্ডগুলো ব্যবহার করুন। `omarchy plugin list` শেল জানে এমন প্রতিটি উইজেটকে তার id সহ ছাপায়, এবং তারপর:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## বারটি লুকানো

`Super + Shift + Space` শেলকে না মেরে বারটিকে বন্ধ করে এবং আবার চালু করে — প্যানেল এবং হটকিগুলো কাজ করতে থাকে, আপনি কেবল পিক্সেলগুলো ফিরে পান। এটি মেনুতেও রয়েছে **Appearance → Menu Bar → Hide Bar**-এর অধীনে।

## কনফিগ ফাইল

এই সবকিছু `~/.config/omarchy/shell.json`-এ, `bar` কী-এর অধীনে সংরক্ষণ করা হয়। এখানে একটি সংক্ষিপ্ত সংস্করণ দেওয়া হলো:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

প্রতিটি উইজেট পাঁচটি লেআউট অ্যারের একটিতে একটি এন্ট্রি, এবং এর সেটিংস ওই এন্ট্রিতেই ইনলাইনে বসে — কোনো আলাদা সেটিংস ফাইল নেই এবং কোনো `config` উপ-অবজেক্ট নেই। ঘড়ির `format`, `formatAlt` (ডান-ক্লিক যা ঘোরায়), এবং `verticalFormat` সবই ঠিক সেখানেই `{ "id": "omarchy.clock" }`-তে থাকে।

`center` হলো বারের মাঝখানের বাক্স: এর ভিতরের সবকিছু স্ক্রিনে একটি গোষ্ঠী হিসাবে কেন্দ্রে থাকে। `centerBegin` এবং `centerEnd` বাক্সের দুই পাশ থেকে ঝুলে থাকে, এভাবেই আবহাওয়া এবং আপডেট ব্যাজ আসা-যাওয়া করার পরও ঘড়ি একদম কেন্দ্রে থাকে। `center`-এ একাধিক উইজেট রাখুন এবং সেগুলো একসাথে কেন্দ্রে থাকবে; এটিকে খালি রাখুন এবং `centerBegin` এবং `centerEnd` বারের মাঝখানে মিলিত হবে।

মনে গেঁথে রাখার মতো একটি নিয়ম: **একবার আপনার নিজের `shell.json` থাকলে, সেটাই প্রামাণ্য**। আপনি কোনো কিছু কাস্টমাইজ না করা পর্যন্ত, শেল Omarchy-এর ডিফল্ট ফাইল পড়ে। আপনি যেই মুহূর্তে একটি উইজেট টানেন, `omarchy bar` চালান, অথবা নিজে ফাইলটি সম্পাদনা করেন, আপনি এর মালিক হয়ে যান — কোনো ডিপ মার্জ নেই, তাই ভবিষ্যতের Omarchy রিলিজগুলোতে নতুন ডিফল্ট উইজেটগুলো আপনার বারে স্বয়ংক্রিয়ভাবে দেখা দেবে না। আপনি যখনই একটি পরিষ্কার সূচনা চান, `omarchy bar defaults` সরবরাহ করা লেআউটটি ফিরিয়ে আনে।

একই ফাইলটি শীর্ষ স্তরে, `bar` কী-এর বাইরে, আপনার নিষ্ক্রিয়তার সময়কালও রাখে: `idle.screensaver` এবং `idle.lock`, দুটোই আপনি নিষ্ক্রিয় হওয়ার পর থেকে সেকেন্ডে। তাই ডিফল্ট স্ক্রিনসেভার 150 সেকেন্ডে শুরু হয় এবং লক 300 সেকেন্ডে।
