# 상단 바

화면 상단을 따라 있는 띠가 Omarchy 바다. 얹어 놓은 상태 표시줄이 아니라 Omarchy 셸의 일부다. 메뉴, 알림, OSD 팝업, 잠금 화면까지 그리는, 오래 실행되는 단 하나의 Quickshell 프로세스다. 그래서 모든 것과 완벽하게 테마가 맞고, 새 앱을 띄우는 대신 패널이 즉시 열린다.

또 항상 화면에 떠 있는 유일한 데스크톱 요소이기도 하니, 그 작은 글리프들이 각각 무슨 일을 하는지 알아둘 가치가 있다.

## 기본 구성

바는 세 섹션으로 이루어져 있다. 왼쪽에는 Omarchy 로고(메뉴 런처)와 워크스페이스 표시기가 있다. 가운데에는 상태 표시기, 시계, Elsewhen(세계 시계), 날씨, Omarchy 업데이트 배지가 있다. 오른쪽에는 시스템 트레이, 키보드 레이아웃(레이아웃이나 입력 방식을 둘 이상 설정했을 때만), 에이전트, bluetooth, network, audio, display, power가 있다.

이 중 몇몇은 할 말이 있을 때만 나타난다. 키보드 레이아웃은 레이아웃이나 입력 방식을 둘 이상 설정했을 때만 나타난다. 업데이트 배지는 Omarchy 업데이트가 기다리고 있을 때만 나타난다.

## 클릭해 보기

거의 모든 위젯이 왼쪽, 오른쪽, 가운데 클릭에 각각 반응하고, 몇몇은 스크롤에도 반응한다. 사람들이 놓치는 부분이 바로 여기다 — 좋은 것들은 대개 오른쪽 버튼과 가운데 버튼 뒤에 숨어 있다.

| 위젯 | 왼쪽 클릭 | 오른쪽 클릭 | 가운데 클릭 / 스크롤 |
| --- | --- | --- | --- |
| 메뉴 | Omarchy 메뉴 | 새 터미널 | — |
| 워크스페이스 | 이 모니터에서 해당 워크스페이스로 포커스 | — | 스크롤: 다음/이전 워크스페이스 |
| 시계 | 달력 팝업 | 레이블 형식 순환 | 가운데 클릭: 시간대 선택기 |
| 세계 시계 | 세계 시계 패널 | 새로고침 | 가운데 클릭: 새로고침 |
| 날씨 | 예보 팝업 | 전체 날씨를 알림으로 표시 | 가운데 클릭: 새로고침 |
| 오디오 | 오디오 패널 | 음소거 | 가운데 클릭: 패널 · 스크롤: 볼륨 |
| 마이크 | 마이크 음소거 | — | 가운데 클릭: 오디오 패널 · 스크롤: 입력 볼륨 |
| 네트워크 | 네트워크 패널 | — | — |
| Bluetooth | Bluetooth 패널 | 라디오 켜기/끄기 | — |
| 디스플레이 | 디스플레이 패널 | — | 스크롤: 밝기 |
| 전원 | 전원 패널 | 배터리 백분율 표시 켜기/끄기 | — |
| 미디어 | 재생/일시 정지 | 커버 아트 팝업 | 가운데 클릭: 다음 · 스크롤: 이전/다음 |
| 에이전트 | 에이전트 패널 | 에이전트 실행 | 가운데 클릭: 사용량 새로고침 |
| 트레이 | 위에 마우스를 올려 서랍 펼치기 | 셰브론을 오른쪽 클릭해 관리 | — |
| Omarchy 업데이트 | 업데이트 실행 | — | — |

그 표에 있는 모든 것이 처음부터 바에 있는 것은 아니다. 미디어 위젯(스크롤되는 곡명과 아티스트가 있는 MPRIS 현재 재생)과 마이크 위젯은 둘 다 내장되어 있지만 기본값은 꺼짐이다 — 원하면 아래 설명대로 추가하면 된다.

## 패널

바 아이콘을 클릭하면 패널이 열린다. 툴팁이 아니라 슬라이더, 목록, 키보드 탐색을 갖춘 제대로 된 팝업이다. 각각 단축키도 있으니 16픽셀짜리 글리프를 조준할 일은 없다:

| 단축키 | 패널 |
| --- | --- |
| `Super + Ctrl + A` | 오디오 |
| `Super + Ctrl + N` | 네트워크 |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | 디스플레이 |
| `Super + Ctrl + P` | 전원 |
| `Super + Ctrl + Alt + D` | 달력 |
| `Super + Ctrl + Alt + E` | 세계 시계 |
| `Super + Ctrl + X` | 에이전트 |
| `Super + Ctrl + 1-9` | 오른쪽 섹션의 n번째 패널 켜기/끄기 |

패널은 읽기 전용 표시가 아니다. 실제로 일을 처리하는 곳이다:

- **오디오**에는 마스터 볼륨 슬라이더, 출력 장치 선택기, 앱별 믹서가 있어, 다른 건 건드리지 않고 그 브라우저 탭 하나만 줄일 수 있다.
- **네트워크**는 Wi-Fi를 스캔하고, 신호 강도를 보여주고, 연결하고, DNS 제공자를 고르게 해준다.
- **Bluetooth**는 장치 목록과 연결/연결 해제, 배터리 잔량을 보여준다.
- **전원**은 배터리 통계를 보여주고, 전원 프로필을 전환하며(배터리와 AC에 대해 서로 다른 선택을 기억한다), 시스템 정보도 일부 출력한다.
- **디스플레이**에는 밝기 슬라이더, 텍스트 크기, 모니터 배율 프리셋이 있고 — 화면이 둘 이상일 때는 — 모니터별 컨트롤도 있다. 더 자세한 이야기는 [모니터](33-monitors.md)를 보라.
- **시계**는 ISO 주 번호와 월 이동이 있는 월간 그리드를 연다.
- **세계 시계**는 도시마다 한 줄씩 유지하며, 그곳의 날씨와 하루가 어떻게 흘러가는지를 보여준다. 검색은 시간대뿐 아니라 마을도 찾으니, Fort Lauderdale는 New York가 아니라 Fort Lauderdale다. 맨 위 줄이 엉뚱한 도시를 가리키면, 그걸 클릭해 지금 어디 있는지 알려줘라; 다른 시간대에 있는 곳을 고르면 시스템 시계도 거기로 이동하는데, 여행할 때 편리하다. 도시 위에 마우스를 올리고 사람 버튼을 클릭하면 누가 거기 사는지 알려줄 수 있다 — 평범한 이름도 되고, 얼굴까지 불러오려면 `@` GitHub 핸들도 된다.

모든 패널은 마우스뿐 아니라 키보드도 받는다: 화살표로 이동하고, Return으로 활성화하고, Tab으로 이웃 패널로 넘어가고, Escape로 닫는다.

`Super + Ctrl + 1-9`는 오른쪽 섹션의 패널을 왼쪽에서 오른쪽으로 세며, 자체 패널이 없는 트레이는 건너뛴다. 그래서 그 숫자가 가리킬 아이콘과 일치한다.

### Tailscale과 Dropbox

**설치 → 서비스**에서 맞는 서비스를 설치해야만 바에 나타나는 위젯이 두 개 더 있고, 둘 다 상태 보고 이상의 일을 하니 알아둘 가치가 있다.

**Tailscale** 패널은 tailnet을 연결하고 끊고, 계정을 전환하고, exit node를 고른다(내 기기들과 Mullvad 지역이 모두 그 목록에 나타난다). 기기를 탐색할 수도 있다 — 하나를 선택한 상태에서 `s`를 누르면 Taildrop으로 파일을 보내는데, 휴대폰이나 다른 노트북으로 파일을 옮기는 가장 빠른 방법이다. `c`는 그 기기의 IP를, `n`은 이름을, `d`는 전체 DNS 이름을 복사한다. 클릭하는 편이 좋다면 각 기기 줄마다 보내기 버튼도 있다. 터미널에서 같은 일을 하는 명령은 `omarchy tailscale send <machine> [file...]`다.

**Dropbox** 패널은 로그인을 처리하고, 사용한 저장 공간이 얼마인지 보여주고, 최근에 동기화된 파일을 나열한다.

어느 서비스를 제거하든 그 위젯은 바에서 다시 사라진다.

## 인디케이터

가운데의 작은 무리가 인디케이터 위젯이다. 켜둔 모드들을 나타내는 상태 글리프들이다: 방해 금지, 야간 조명, 대기 중인 [리마인더](09-reminders.md), 진행 중인 화면 녹화, 깨어 있기가 있고, 패스워드 없는 sudo가 켜져 있거나 누군가 원격 세션에 접속해 있을 때의 경고도 있다. 모드가 활성화되면 켜지고, 아니면 눈에 띄지 않게 물러나 있다 — 비활성 인디케이터가 있을 법한 바로 옆자리에 마우스를 올리면 그것들을 엿볼 수 있다. 인디케이터를 클릭하면 그 모드가 켜졌다 꺼졌다 한다. 상태 전용인 것이 하나 더 있다: 누군가 gliff를 통해 이 기기에 접속해 있는 동안 원격 세션이 빨갛게 켜진다.

항상 보이게 하고 싶다면, 위젯에서 `alwaysShow`를 `true`로 설정하라. 일부만 신경 쓴다면, 원하는 것들을 `items`에 나열하면 된다: `["Dnd", "Reminder", "NightLight"]`. 인디케이터 위젯은 둘 이상 둘 수 있으니, 섹션마다 서로 다른 부분집합을 보여줄 수 있다.

## 바 재배열하기

바는 스스로를 설정한다. 뭔가를 옮기려고 설정 파일을 열 필요가 없다.

가운데쯤의 바 빈 곳을 잡아 다른 화면 가장자리를 향해 끌면, 바가 그리로 이동한다 — 왼쪽, 오른쪽, 위쪽, 아래쪽 모두 되고, 모든 위젯이 적응한다(세로 바는 컴팩트한 아이콘 전용 형태로 대체된다). 클릭하고 누르고 있어도 같은 드래그가 시작된다. 그 같은 빈 공간을 왼쪽 버튼으로 더블 클릭하면 바 배경이 투명에서 유리 질감으로, 다시 불투명으로 순환한다. 그리고 어떤 위젯이든 끌어서 순서를 바꾸거나 다른 섹션에 던져 넣으면 된다; 나머지 위젯들은 떨어질 자리를 비워주려고 양쪽으로 벌어진다.

바의 가운데는 상자다: 그 안에 있는 것은 한 그룹으로서 가운데에 머물고, 양옆의 위젯들은 그 가장자리에서 매달린다. 위젯을 끄는 동안 상자는 윤곽선으로 표시되고, 비어 있을 때는 바를 가로지르는 선으로 표시되며, 그 안에 떨어뜨릴 수도 있고 옆에 떨어뜨릴 수도 있다. 떨어뜨릴 곳이 상자 안이 되면, 상자는 위젯을 받아들이려고 커진다.

곁에 두고 싶지만 항상 눈에 띄게 하고 싶지는 않은 위젯은 트레이의 서랍에 넣을 수 있다: 트레이 위로 끌면, 서랍이 열려 그 위젯을 받아들인다. 앱 아이콘 뒤에 자리 잡고, 서랍이 나타날 때마다 나타나고, 자신의 패널이 떠 있는 동안 서랍을 열어둔다. 다시 바 위로 끌어내면 원래 자리로 돌아간다.

메뉴에서 고르는 편이 좋다면, **모양 → 메뉴 바**에 위치가 있고, **바 배경**에서 바가 그려지는 방식을 고른다: **불투명 바**, **유리 질감 바**(뒤가 비치고, 그 뒤에 있는 것이 흐려진다), 또는 **투명 바**.

같은 일들을 명령으로도 할 수 있는데, [dotfiles](31-dotfiles.md) 설정에 원하는 것이 바로 그것이다:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

위젯을 완전히 추가하거나 제거하려면, 플러그인 명령을 쓰라. `omarchy plugin list`는 셸이 아는 모든 위젯을 그 id와 함께 출력하고, 그다음은:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 바 숨기기

`Super + Shift + Space`는 셸을 죽이지 않고 바를 껐다가 다시 켠다 — 패널과 단축키는 계속 작동하고, 픽셀만 되찾는다. 메뉴의 **모양 → 메뉴 바 → 바 숨기기**에도 있다.

## 설정 파일

이 모든 것은 `~/.config/omarchy/shell.json`의 `bar` 키 아래에 저장된다. 다듬은 버전이 여기 있다:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

모든 위젯은 다섯 개의 레이아웃 배열 중 하나에 있는 항목 하나이며, 그 설정은 그 항목에 인라인으로 앉아 있다 — 별도의 설정 파일도, `config` 하위 객체도 없다. 시계의 `format`, `formatAlt`(오른쪽 클릭으로 순환되는 것), `verticalFormat`은 모두 `{ "id": "omarchy.clock" }` 바로 거기에 산다.

`center`는 바 가운데의 상자다: 그 안에 있는 모든 것은 하나의 그룹으로서 화면 가운데에 정렬된다. `centerBegin`과 `centerEnd`는 상자 양옆에 매달리는데, 날씨와 업데이트 배지가 들락날락해도 시계가 정확히 가운데에 머무는 것이 그 덕이다. `center`에 위젯을 둘 이상 넣으면 함께 가운데 정렬되고; 비워 두면 `centerBegin`과 `centerEnd`가 바 가운데에서 만난다.

내면화해둘 가치가 있는 규칙 하나: **자신만의 `shell.json`을 갖게 된 순간부터, 그게 정본이다**. 아무것도 커스터마이징하지 않았다면, 셸은 Omarchy의 기본 파일을 읽는다. 위젯을 끌거나, `omarchy bar`를 실행하거나, 파일을 직접 편집하는 순간부터, 그건 네 것이다 — 깊은 병합은 없으니, 앞으로의 Omarchy 릴리스에 나오는 새 기본 위젯이 바에 자동으로 나타나지는 않는다. 깨끗하게 다시 시작하고 싶을 때마다 `omarchy bar defaults`가 출고 시 레이아웃을 되돌려놓는다.

같은 파일은 `bar` 키 바깥의 최상위 레벨에 유휴 타이밍도 담는다: `idle.screensaver`와 `idle.lock`, 둘 다 유휴 상태가 된 뒤의 초 단위다. 그래서 기본 스크린세이버는 150초에, 잠금은 300초에 시작된다.
