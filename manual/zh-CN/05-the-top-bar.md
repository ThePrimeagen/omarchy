# 顶部栏

屏幕顶部那条就是 Omarchy 栏。它不是外挂上去的状态栏，而是 Omarchy shell 的一部分。那个长期运行的单个 Quickshell 进程还负责绘制菜单、通知、OSD 弹窗和锁屏。所以它的主题能跟其它一切完美一致，面板也能立刻打开，而不是再启动一个新应用。

它也是桌面上唯一始终留在屏幕上的部分，所以值得弄清那些小字形都干什么。

## 默认上面有什么

这条栏分为三个部分。左侧是 Omarchy 标志（菜单启动器）和工作区指示器。中间有状态指示器、时钟、Elsewhen（世界时钟）、天气和 Omarchy 更新徽章。右侧有：系统托盘、键盘布局（配置了多个布局或输入法时才显示）、agents、蓝牙、网络、音频、显示和电源。

其中有几个只在有话要说时才出现。键盘布局只有在你配置了多个布局或输入法时才会出现。更新徽章只有在有 Omarchy 更新在等待时才会出现。

## 到处点一点

几乎每个小部件都对左键、右键和中键点击有所响应，有几个还响应滚动。这部分很容易被漏掉——很多好东西就藏在右键和中键里。

| 小部件 | 左键 | 右键 | 中键 / 滚动 |
| --- | --- | --- | --- |
| 菜单 | Omarchy 菜单 | 新终端 | — |
| 工作区 | 在此显示器上聚焦该工作区 | — | 滚动：下一个/上一个工作区 |
| 时钟 | 日历弹窗 | 循环切换标签格式 | 中键：时区选择器 |
| 世界时钟 | 世界时钟面板 | 刷新 | 中键：刷新 |
| 天气 | 天气预报弹窗 | 以通知形式显示完整天气 | 中键：刷新 |
| 音频 | 音频面板 | 静音 | 中键：面板 · 滚动：音量 |
| 麦克风 | 将麦克风静音 | — | 中键：音频面板 · 滚动：输入音量 |
| 网络 | 网络面板 | — | — |
| 蓝牙 | 蓝牙面板 | 开关无线电 | — |

| Omarchy 更新 | 运行更新 | — | — |

那张表里的东西并非全都在你的栏上现成摆着。媒体小部件（MPRIS 正在播放，带滚动显示的曲目和艺人）和麦克风小部件都已内置，但默认关闭——想要的话就加上它们，方法见下文。

## 面板

点击栏图标会打开一个面板，那是一个正经的弹窗，带滑块、列表和键盘导航，而不是一个工具提示。每个面板也都有快捷键，所以你永远不用去瞄准一个 16 像素的字形：

| 快捷键 | 面板 |
| --- | --- |
| `Super + Ctrl + A` | 音频 |
| `Super + Ctrl + N` | 网络 |
| `Super + Ctrl + B` | 蓝牙 |
| `Super + Ctrl + D` | 显示 |
| `Super + Ctrl + P` | 电源 |
| `Super + Ctrl + Alt + D` | 日历 |
| `Super + Ctrl + Alt + E` | 世界时钟 |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | 切换右侧部分中的第 n 个面板 |

这些面板不是只读的读数。它们是你真正干活的地方：

- **音频**有主音量滑块、输出设备选择器和按应用划分的混音器，所以你可以把那一个浏览器标签页调小声，而不用动其它所有东西。
- **网络**会扫描 Wi-Fi，显示信号强度，进行连接，并让你选择一个 DNS 提供商。
- **蓝牙**会列出你的设备，带连接/断开和电量。
- **电源**会显示电池统计，切换电源配置文件（它会为电池和 AC 分别记住一个选择），并打印一些系统信息。
- **显示**带有亮度滑块、文字大小、显示器缩放预设，而且——当你有多个屏幕时——还有按显示器划分的控制。更深入的故事见[显示器](33-monitors.md)。
- **时钟**会打开一个月度网格，带 ISO 周数和月份步进。
- **世界时钟**每个城市占一行，带它的天气和它那一天过得怎么样。搜索既能找城镇，也能找时区，所以 Fort Lauderdale 就是 Fort Lauderdale，而不是 New York。如果顶部那一行写错了城市，点击它并告诉它你在哪儿；选一个另一个时区的地方，系统时钟也会跟着移过去，旅行时很方便。把鼠标悬停在一个城市上，点击人物按钮，说明谁住在那里——可以用普通名字，也可以用 `@` GitHub 账号，这样能把他们的头像也带过来。

每个面板都既支持键盘，也支持鼠标：方向键移动，Return 激活，Tab 步进到相邻的面板，Escape 关闭。

`Super + Ctrl + 1-9` 按从左到右的顺序数右侧部分里的面板，跳过托盘，因为它没有自己的面板。所以数字跟你会指着的那个图标正好对得上。

### Tailscale 和 Dropbox

还有两个小部件，只有当你从**安装 → 服务**安装了对应的服务之后才会出现在栏上，而且两个都值得了解一下，因为它们不只是报告状态。

**Tailscale** 面板可以连接和断开 tailnet，在账号之间切换，并选择一个 exit node（你自己的机器和 Mullvad 地区都会出现在那个列表里）。它还能浏览你的机器——选中一台之后，按 `s` 就能通过 Taildrop 把文件发送给它，这是把文件移到你的手机或另一台笔记本上最快的方法。`c` 复制那台机器的 IP，`n` 复制它的名字，`d` 复制它的完整 DNS 名称。每行机器上也有一个发送按钮，如果你更喜欢点击的话。从终端做同样的事情是 `omarchy tailscale send <machine> [file...]`。

**Dropbox** 面板处理登录，显示你已经用了多少存储空间，并列出最近同步的文件。

移除任一服务都会把对应的小部件从栏上拿掉。

## 指示器

中间那一小簇就是指示器小部件。它们是为你已开启的模式准备的状态字形：勿扰、夜灯、一个排队的[提醒](09-reminders.md)、正在进行的屏幕录制和保持唤醒，外加在 passwordless sudo 开启时或有人连接到远程会话时的警告。模式激活时它们会亮起来，其它时候就躲开——把鼠标悬停在它们旁边、那些未激活的指示器本该待着的地方，就能偷看一下它们。点击一个指示器就会切换该模式。还有一个仅用于显示状态：当有人通过 gliff 连接到这台机器时，远程会话会亮起红色。

如果你更希望它们始终可见，就在该小部件上把 `alwaysShow` 设置为 `true`。如果你只关心其中几个，就在 `items` 中列出你想要的那些：`["Dnd", "Reminder", "NightLight"]`。你可以拥有多个指示器小部件，所以不同部分可以显示不同的子集。

## 重新排列栏

这条栏会自己配置自己。你不用打开一个配置文件来移动东西。

抓住中间周围一块空着的栏，把它拖向另一个屏幕边缘，栏就会移到那里——左、右、上、下都可以，而且每个小部件都会适应（竖直栏会回落为紧凑的仅图标形式）。按住点击会启动同样的拖动。在同一块空地方双击左键，可以把栏背景从透明循环切换为毛玻璃、再到不透明。还可以拖动任何小部件来重新排序，或者把它扔进另一个部分；其它小部件会滑开，在它将要落下的地方腾出空间。

栏的中间是一个盒子：里面的东西会作为一个整体保持居中，它两侧的小部件则挂在它的边缘上。拖动小部件时，这个盒子会显示为一个轮廓，或者在它是空的时候显示为一条横贯栏的线，你可以把它放进里面，也可以放在它旁边。当一次放置会落在这个盒子里时，盒子会变大，把小部件收进来。

一个你想留着、但又不想它总是露在外面的小部件，可以放进托盘的抽屉里：把它拖到托盘上，抽屉就会打开来接它。它会待在应用图标的后面，只要抽屉出现它就会出现，而且在它的面板打开时会让抽屉保持打开。把它拖回栏上就能把它放回去。

如果你更喜欢从菜单里选，**外观 → 菜单栏**里有位置，**栏背景**决定这条栏如何绘制：**不透明栏**、**毛玻璃栏**（透过它能看见后面的内容，后面的内容会被模糊），或**透明栏**。

同样的事情也有命令，这正是你为 [dotfiles](31-dotfiles.md) 设置所想要的：

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

要整个添加或移除一个小部件，使用插件命令。`omarchy plugin list` 会打印 shell 所知道的每个小部件，连同它的 id，然后：

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## 隐藏栏

`Super + Shift + Space` 可以在不杀死 shell 的情况下把栏关掉再打开——面板和快捷键依然能用，你只是把那些像素拿回来了。它也在菜单里的**外观 → 菜单栏 → 隐藏栏**下面。

## 配置文件

这一切都存储在 `~/.config/omarchy/shell.json` 中，位于 `bar` 键下面。这是一个精简版：

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

每个小部件都是五个布局数组之一中的一个条目，它的设置就内联在那个条目上——没有单独的设置文件，也没有 `config` 子对象。时钟的 `format`、`formatAlt`（右键循环切换到的那个）和 `verticalFormat` 都直接住在 `{ "id": "omarchy.clock" }` 上。

`center` 是栏中间的那个盒子：里面的所有东西会作为一个整体在屏幕上居中。`centerBegin` 和 `centerEnd` 挂在盒子的两侧，这正是时钟能始终稳居正中、哪怕天气和更新徽章来来去去的原因。把多个小部件放进 `center`，它们会一起居中；把它留空，`centerBegin` 和 `centerEnd` 就会在栏的中间相遇。

有一条规则值得牢记：**一旦你有了自己的 `shell.json`，它就是权威的**。在你自定义任何东西之前，shell 读取的是 Omarchy 的默认文件。你拖动一个小部件、运行 `omarchy bar`，或者亲自编辑这个文件的那一刻起，你就接管了它——没有深度合并，所以未来 Omarchy 版本中新增的默认小部件不会自动出现在你的栏上。每当你想要一个干净的起点时，`omarchy bar defaults` 都会把出厂布局放回来。

同一个文件还在顶层、`bar` 键之外保存了你的空闲计时：`idle.screensaver` 和 `idle.lock`，两者都是从你进入空闲状态起算的秒数。所以默认的屏保在 150 秒时启动，锁屏在 300 秒时启动。
