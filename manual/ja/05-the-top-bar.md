# トップバー

画面上部の帯が Omarchy バーだ。後付けのステータスバーではなく、Omarchy シェルの一部であり、メニュー、通知、OSD ポップアップ、ロック画面も描画する、単一の長時間動作する Quickshell プロセスだ。だからこそ、他のすべてと完璧にテーマが合い、新しいアプリを起動するのではなくパネルが瞬時に開く。

デスクトップの中で常に画面に表示されている唯一の要素でもあるので、あの小さなグリフが何をするのか知っておく価値がある。

## デフォルトで表示されるもの

バーは3つのセクションに分かれている。左には Omarchy ロゴ（メニューランチャー）とワークスペースインジケーターがある。中央にはステータスインジケーター、時計、Elsewhen（世界時計）、天気、Omarchy アップデートバッジがある。右にはシステムトレイ、キーボードレイアウト（複数のレイアウトまたは入力メソッドを設定している場合）、エージェント、Bluetooth、ネットワーク、オーディオ、ディスプレイ、電源がある。

そのうちいくつかは、伝えることがあるときだけ表示される。キーボードレイアウトは、複数のレイアウトまたは入力メソッドを設定した場合にのみ表示される。アップデートバッジは、Omarchy のアップデートが待機しているときにのみ表示される。

## クリック操作

ほぼすべてのウィジェットは左クリック、右クリック、中クリックで何かを行い、いくつかはスクロールにも反応する。ここがみんな見落とす部分だ。良いものの多くは右ボタンと中ボタンに隠れている。

| ウィジェット | 左クリック | 右クリック | 中クリック / スクロール |
| --- | --- | --- | --- |
| メニュー | Omarchy メニュー | 新しいターミナル | — |
| ワークスペース | このモニターでそのワークスペースにフォーカス | — | スクロール：次/前のワークスペース |
| 時計 | カレンダーポップアップ | ラベル形式を切り替え | 中クリック：タイムゾーン選択 |
| 世界時計 | 世界時計パネル | 更新 | 中クリック：更新 |
| 天気 | 予報ポップアップ | 通知として天気の詳細 | 中クリック：更新 |
| オーディオ | オーディオパネル | ミュート | 中クリック：パネル · スクロール：音量 |
| マイク | マイクをミュート | — | 中クリック：オーディオパネル · スクロール：入力音量 |
| ネットワーク | ネットワークパネル | — | — |
| Bluetooth | Bluetooth パネル | 無線のオン/オフ | — |
| ディスプレイ | ディスプレイパネル | — | スクロール：明るさ |
| 電源 | 電源パネル | バッテリー残量表示のオン/オフ | — |
| メディア | 再生/一時停止 | カバーアートのポップアップ | 中クリック：次へ · スクロール：前へ/次へ |
| エージェント | エージェントパネル | エージェントを起動 | 中クリック：使用量を更新 |
| トレイ | ホバーでドロワーを表示 | シェブロンを右クリックして管理 | — |
| Omarchy アップデート | アップデートを実行 | — | — |

その表のすべてが、最初からバーにあるわけではない。メディアウィジェット（スクロールする曲名とアーティストを表示する MPRIS の再生中表示）とマイクウィジェットはどちらも組み込みだが、デフォルトではオフになっている。欲しければ、後述のとおり追加すればいい。

## パネル

バーのアイコンをクリックするとパネルが開く。これはツールチップではなく、スライダー、リスト、キーボードナビゲーションを備えたまともなポップアップだ。各パネルにはホットキーもあるので、16ピクセルのグリフを狙う必要は決してない。

| ホットキー | パネル |
| --- | --- |
| `Super + Ctrl + A` | オーディオ |
| `Super + Ctrl + N` | ネットワーク |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ディスプレイ |
| `Super + Ctrl + P` | 電源 |
| `Super + Ctrl + Alt + D` | カレンダー |
| `Super + Ctrl + Alt + E` | 世界時計 |
| `Super + Ctrl + X` | エージェント |
| `Super + Ctrl + 1-9` | 右セクションの n 番目のパネルを切り替え |

パネルは読み取り専用の表示ではない。実際に操作する場所だ。

- **オーディオ**にはマスター音量スライダー、出力デバイス選択、アプリごとのミキサーがあり、他のすべてに触れずにあのブラウザタブ1つだけ音量を下げられる。
- **ネットワーク**は Wi-Fi をスキャンし、信号強度を表示し、接続し、DNS プロバイダーを選べる。
- **Bluetooth**はデバイスを一覧表示し、接続/切断とバッテリーレベルを示す。
- **電源**はバッテリー統計を表示し、電源プロファイルを切り替え（バッテリー時と AC 時で別々の選択を記憶する）、システム情報も少し表示する。
- **ディスプレイ**には明るさスライダー、テキストサイズ、モニターのスケーリングプリセットがあり、画面が複数ある場合はモニターごとのコントロールもある。詳しくは[モニター](33-monitors.md)を参照。
- **時計**は ISO 週番号付きの月グリッドを開き、月を移動できる。
- **世界時計**は都市ごとに行を保持し、その天気とその日の進み具合を表示する。検索ではタイムゾーンだけでなく町も見つかるので、Fort Lauderdale は New York ではなく Fort Lauderdale だ。上部の行に間違った都市名が出ている場合は、それをクリックして現在地を伝えればいい。別のタイムゾーンの場所を選ぶとシステム時計もそこへ移動するので、旅行時に便利だ。都市にホバーして人物ボタンをクリックすると、そこに住んでいる人を指定できる。通常の名前でも、`@` GitHub ハンドルでもよく、顔も一緒に表示される。

すべてのパネルはマウスだけでなくキーボードでも操作できる。矢印キーで移動し、Return で実行し、Tab で隣のパネルへ移動し、Escape で閉じる。

`Super + Ctrl + 1-9` は右セクションのパネルを左から右へ数える。トレイは独自のパネルを持たないのでスキップする。だから番号は、指さすアイコンと一致する。

### Tailscale と Dropbox

対応するサービスを **インストール → サービス** からインストールすると、さらに2つのウィジェットがバーに表示される。どちらもステータスを報告する以上のことをするので、知っておく価値がある。

**Tailscale** パネルは tailnet の接続と切断、アカウントの切り替え、exit node の選択を行う（自分のマシンと Mullvad の地域の両方がそのリストに表示される）。マシンの閲覧もでき、1つ選択した状態で `s` を押すと Taildrop 経由でファイルを送信する。これは携帯電話や別のノートパソコンへファイルを移動する最速の方法だ。`c` はマシンの IP を、`n` はその名前を、`d` はその完全な DNS 名をコピーする。各マシンの行には送信ボタンもあるので、クリックしたい場合はそちらを使えばいい。ターミナルから同じことをするには `omarchy tailscale send <machine> [file...]` だ。

**Dropbox** パネルはログインを処理し、使用したストレージ容量を表示し、最近同期されたファイルを一覧表示する。

どちらかのサービスを削除すると、そのウィジェットはバーから消える。

## インジケーター

中央の小さな集まりがインジケーターウィジェットだ。これらは有効にしたモードのステータスグリフであり、おやすみモード、ナイトライト、キューに入った[リマインダー](09-reminders.md)、アクティブな画面録画、スリープ防止に加え、パスワードなし sudo がオンのときや誰かがリモートセッションに接続しているときの警告がある。モードがアクティブなときは点灯し、それ以外のときは邪魔にならない。非アクティブなものが並ぶはずのすぐ横にホバーすれば、それらを覗き見できる。インジケーターをクリックするとそのモードが切り替わる。もう1つはステータス専用だ。リモートセッションは、誰かが gliff 経由でこのマシンに接続している間、赤く点灯する。

常に表示しておきたい場合は、ウィジェットで `alwaysShow` を `true` に設定する。一部だけ気にする場合は、欲しいものを `items` に列挙する：`["Dnd", "Reminder", "NightLight"]`。インジケーターウィジェットは複数持てるので、セクションごとに異なるサブセットを表示できる。

## バーの並び替え

バーは自分で設定する。物を動かすために設定ファイルを開く必要はない。

中央付近のバーの空いた部分を掴んで別の画面端へドラッグすると、バーはそこへ移動する。左、右、上、下すべて機能し、すべてのウィジェットが適応する（縦型バーはコンパクトなアイコンのみの形式にフォールバックする）。クリックしたまま保持しても同じドラッグが始まる。その同じ空きスペースを左ダブルクリックすると、バーの背景が透明からガラス質、不透明へと循環する。任意のウィジェットをドラッグすれば並び替えたり、別のセクションに放り込んだりできる。他のウィジェットは、着地する場所にスペースを作るためにスライドして離れる。

バーの中央はボックスだ。その中にあるものは1つのグループとして中央に留まり、その両側のウィジェットはその端にぶら下がる。ウィジェットをドラッグしている間、ボックスはアウトラインとして表示され、空のときはバーを横切る線として表示され、その中にも横にもドロップできる。ドロップがボックス内に着地する場合は、ボックスが広がってウィジェットを取り込む。

常に視界に入れておきたくないが手元には置きたいウィジェットは、トレイのドロワーに入れられる。トレイの上にドラッグすると、ドロワーが開いてそれを受け取る。それはアプリアイコンの後ろに位置し、ドロワーが表示されるたびに現れ、そのパネルが開いている間ドロワーを開いたままにする。バーへドラッグして戻せば元に戻る。

メニューから選びたい場合は、**外観 → メニューバー** に位置があり、**バーの背景** でバーの描画方法を選ぶ：**不透明なバー**、**ガラス質のバー**（半透明で、背後にあるものがぼかされる）、または **透明なバー**。

同じことにはコマンドもある。[dotfiles](31-dotfiles.md) セットアップにはこちらが欲しくなるだろう。

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

ウィジェットを丸ごと追加または削除するには、プラグインコマンドを使う。`omarchy plugin list` はシェルが知っているすべてのウィジェットをその id と共に表示する。次にこうする。

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## バーを隠す

`Super + Shift + Space` はシェルを終了させずにバーの表示をオフ/オンに切り替える。パネルとホットキーは引き続き機能し、ピクセルだけを取り戻せる。メニューの **外観 → メニューバー → バーを隠す** にもある。

## 設定ファイル

すべては `~/.config/omarchy/shell.json` の `bar` キーの下に保存される。トリミングしたバージョンを次に示す。

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

すべてのウィジェットは5つのレイアウト配列のいずれかにある1つのエントリであり、その設定はそのエントリにインラインで置かれる。別の設定ファイルはなく、`config` サブオブジェクトもない。時計の `format`、`formatAlt`（右クリックで切り替わる先）、`verticalFormat` はすべて `{ "id": "omarchy.clock" }` のすぐそこにある。

`center` はバーの中央にあるボックスだ。その中のすべては1つのグループとして画面の中央に配置される。`centerBegin` と `centerEnd` はボックスの両側にぶら下がり、そのおかげで天気やアップデートバッジが現れたり消えたりしても時計はど真ん中に留まる。`center` に複数のウィジェットを入れると、それらは一緒に中央に配置される。空にしておくと `centerBegin` と `centerEnd` がバーの中央で合う。

内面化しておく価値のあるルールが1つある：**自分の `shell.json` を持った瞬間、それが正となる**。何もカスタマイズしていない間は、シェルは Omarchy のデフォルトファイルを読む。ウィジェットをドラッグしたり、`omarchy bar` を実行したり、自分でファイルを編集したりした瞬間、それは自分のものになる。深いマージはないので、将来の Omarchy リリースの新しいデフォルトウィジェットは自動的にはバーに現れない。クリーンな状態にしたくなったらいつでも `omarchy bar defaults` で出荷時のレイアウトに戻せる。

同じファイルには、アイドル時間もトップレベルで、`bar` キーの外側に保持される：`idle.screensaver` と `idle.lock` で、どちらもアイドルになってからの秒数だ。だからデフォルトのスクリーンセーバーは150秒で起動し、ロックは300秒で起動する。
