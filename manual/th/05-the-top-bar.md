# แถบด้านบน

แถบที่ทอดไปตามด้านบนของหน้าจอคือแถบของ Omarchy ไม่ใช่แถบสถานะที่นำมาติดเสริมเข้าไป แต่เป็นส่วนหนึ่งของเชลล์ของ Omarchy ซึ่งเป็นกระบวนการ Quickshell ที่ทำงานต่อเนื่องเพียงกระบวนการเดียว และยังเป็นผู้วาดเมนู การแจ้งเตือน ป๊อปอัป OSD และหน้าจอล็อกด้วย นั่นคือเหตุผลที่ทุกอย่างมีธีมเข้ากันอย่างสมบูรณ์ และแผงต่าง ๆ เปิดขึ้นมาทันทีแทนที่จะต้องเรียกแอปใหม่ขึ้นมา

แถบนี้ยังเป็นชิ้นส่วนเดียวของเดสก์ท็อปที่อยู่บนหน้าจอตลอดเวลา จึงคุ้มค่าที่จะรู้ว่าสัญลักษณ์เล็ก ๆ เหล่านั้นแต่ละอย่างทำอะไร

## มีอะไรอยู่บนนั้นโดยค่าเริ่มต้น

แถบมีสามส่วน ทางซ้ายคือโลโก้ Omarchy (ตัวเปิดเมนู) และตัวบ่งชี้พื้นที่ทำงาน ตรงกลางมีตัวบ่งชี้สถานะ นาฬิกา Elsewhen (นาฬิกาโลก) สภาพอากาศ และป้ายอัปเดตของ Omarchy ทางขวาได้แก่ ถาดระบบ รูปแบบแป้นพิมพ์ (เมื่อมีการตั้งค่ามากกว่าหนึ่งรูปแบบหรือวิธีป้อนข้อมูล) agents, bluetooth, เครือข่าย เสียง จอแสดงผล และพลังงาน

บางรายการจะปรากฏเฉพาะเมื่อมีเรื่องต้องบอกเท่านั้น รูปแบบแป้นพิมพ์จะปรากฏเฉพาะเมื่อคุณตั้งค่ามากกว่าหนึ่งรูปแบบหรือวิธีป้อนข้อมูลไว้ ส่วนป้ายอัปเดตจะปรากฏเฉพาะเมื่อมีอัปเดตของ Omarchy รออยู่

## แผงต่าง ๆ

การคลิกไอคอนบนแถบจะเปิดแผง ซึ่งเป็นป๊อปอัปอย่างเหมาะสมที่มีตัวเลื่อน รายการ และการนำทางด้วยแป้นพิมพ์ แทนที่จะเป็นเพียงคำแนะนำเครื่องมือ แต่ละแผงยังมีปุ่มลัดด้วย คุณจึงไม่ต้องเล็งไปที่สัญลักษณ์ขนาด 16 พิกเซลเลย:

| ปุ่มลัด | แผง |
| --- | --- |
| `Super + Ctrl + A` | เสียง |
| `Super + Ctrl + N` | เครือข่าย |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | จอแสดงผล |
| `Super + Ctrl + P` | พลังงาน |
| `Super + Ctrl + Alt + D` | ปฏิทิน |
| `Super + Ctrl + Alt + E` | นาฬิกาโลก |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | สลับแผงที่ n ในส่วนด้านขวา |

แผงต่าง ๆ ไม่ใช่แค่หน้าจอแสดงค่าอ่านอย่างเดียว แต่เป็นที่ที่คุณลงมือทำสิ่งนั้นจริง ๆ:

- **เสียง** มีตัวเลื่อนระดับเสียงหลัก ตัวเลือกอุปกรณ์ส่งออก และมิกเซอร์แยกตามแอป คุณจึงลดเสียงแท็บเบราว์เซอร์นั้นแท็บเดียวได้โดยไม่กระทบอย่างอื่น
- **เครือข่าย** สแกนหา Wi-Fi แสดงความแรงของสัญญาณ เชื่อมต่อ และให้คุณเลือกผู้ให้บริการ DNS
- **Bluetooth** แสดงรายการอุปกรณ์ของคุณพร้อมการเชื่อมต่อ/ตัดการเชื่อมต่อและระดับแบตเตอรี่
- **พลังงาน** แสดงสถิติแบตเตอรี่ สลับโปรไฟล์พลังงาน (โดยจะจำตัวเลือกแยกกันสำหรับแบตเตอรี่และ AC) และแสดงข้อมูลระบบบางอย่าง
- **จอแสดงผล** มีตัวเลื่อนความสว่าง ขนาดข้อความ ค่าที่ตั้งไว้ล่วงหน้าสำหรับการปรับขนาดจอ และเมื่อคุณมีมากกว่าหนึ่งหน้าจอ ก็จะมีตัวควบคุมแยกตามจอด้วย ดูเรื่องราวที่ลึกกว่านี้ได้ที่ [จอภาพ](33-monitors.md)
- **นาฬิกา** เปิดตารางรายเดือนที่มีหมายเลขสัปดาห์แบบ ISO และการเลื่อนเปลี่ยนเดือน
- **นาฬิกาโลก** เก็บไว้แถวละหนึ่งเมือง พร้อมสภาพอากาศของเมืองนั้นและวันของเมืองนั้นดำเนินไปอย่างไร การค้นหาจะหาเมืองเล็ก ๆ ได้เช่นเดียวกับเขตเวลา ดังนั้น Fort Lauderdale ก็คือ Fort Lauderdale ไม่ใช่ New York หากบรรทัดด้านบนระบุเมืองผิด ให้คลิกที่บรรทัดนั้นแล้วบอกว่าคุณอยู่ที่ไหน เลือกที่ใดที่หนึ่งที่อยู่อีกเขตเวลา และนาฬิการะบบจะย้ายไปที่นั่นด้วย ซึ่งมีประโยชน์มากเมื่อคุณเดินทาง เลื่อนเมาส์ไปวางบนเมืองแล้วคลิกปุ่มรูปคนเพื่อบอกว่าใครอาศัยอยู่ที่นั่น ใช้ชื่อธรรมดา หรือใช้ที่จับ GitHub ที่ขึ้นต้นด้วย `@` เพื่อนำใบหน้าของพวกเขามาด้วย

ทุกแผงใช้แป้นพิมพ์ได้เช่นเดียวกับเมาส์: ลูกศรใช้เลื่อน, Return ใช้เปิดใช้งาน, Tab ใช้ก้าวไปยังแผงข้างเคียง และ Escape ใช้ปิด

`Super + Ctrl + 1-9` นับแผงจากซ้ายไปขวาในส่วนด้านขวา โดยข้ามถาดไปเพราะถาดไม่มีแผงของตัวเอง ดังนั้นตัวเลขจะตรงกับไอคอนที่คุณจะชี้ไปหา

### Tailscale และ Dropbox

วิดเจ็ตอีกสองตัวจะปรากฏบนแถบเฉพาะเมื่อคุณติดตั้งบริการที่ตรงกันจาก **ติดตั้ง → บริการ** เท่านั้น และทั้งสองตัวควรรู้จักไว้เพราะทำได้มากกว่าแค่รายงานสถานะ

แผง **Tailscale** ใช้เชื่อมต่อและตัดการเชื่อมต่อ tailnet สลับระหว่างบัญชี และเลือก exit node (ทั้งเครื่องของคุณเองและภูมิภาคต่าง ๆ ของ Mullvad จะปรากฏในรายการนั้น) นอกจากนี้ยังเรียกดูเครื่องต่าง ๆ ของคุณได้ และเมื่อเลือกเครื่องหนึ่งไว้แล้ว `s` จะส่งไฟล์ไปยังเครื่องนั้นผ่าน Taildrop ซึ่งเป็นวิธีที่เร็วที่สุดในการย้ายไฟล์ไปยังโทรศัพท์หรือแล็ปท็อปอีกเครื่องของคุณ `c` คัดลอก IP ของเครื่อง, `n` คัดลอกชื่อของเครื่อง และ `d` คัดลอกชื่อ DNS แบบเต็มของเครื่อง ในแต่ละแถวของเครื่องยังมีปุ่มส่งให้ด้วย หากคุณอยากคลิกมากกว่า สิ่งเดียวกันจากเทอร์มินัลคือ `omarchy tailscale send <machine> [file...]`

แผง **Dropbox** จัดการการเข้าสู่ระบบ แสดงว่าคุณใช้พื้นที่เก็บข้อมูลไปเท่าใด และแสดงรายการไฟล์ที่ซิงค์ล่าสุด

การลบบริการใดบริการหนึ่งออกจะนำวิดเจ็ตของบริการนั้นออกจากแถบไปด้วย

## ตัวบ่งชี้

กลุ่มเล็ก ๆ ตรงกลางคือวิดเจ็ตตัวบ่งชี้ เหล่านี้คือสัญลักษณ์สถานะสำหรับโหมดที่คุณเปิดไว้: ห้ามรบกวน แสงกลางคืน [ตัวเตือน](09-reminders.md) ที่อยู่ในคิว การบันทึกหน้าจอที่กำลังทำงานอยู่ และการปลุกให้ตื่นไว้ตลอด พร้อมคำเตือนขณะที่ sudo แบบไม่ใช้รหัสผ่านเปิดอยู่ หรือมีคนเชื่อมต่อเข้ามาในเซสชันระยะไกล พวกมันจะสว่างขึ้นเมื่อโหมดนั้นทำงานอยู่ และในเวลาอื่นก็จะหลบไปให้พ้นทาง เลื่อนเมาส์ไปวางข้าง ๆ พวกมัน ตรงที่ตัวที่ไม่ได้ทำงานจะอยู่ เพื่อแอบดูตัวเหล่านั้น การคลิกตัวบ่งชี้จะสลับโหมดนั้น อีกตัวหนึ่งเป็นแบบแสดงสถานะอย่างเดียว: เซสชันระยะไกลจะสว่างเป็นสีแดงขณะที่ใครบางคนเชื่อมต่อเข้ามายังเครื่องนี้ผ่าน gliff

หากคุณอยากให้พวกมันมองเห็นอยู่เสมอ ให้ตั้ง `alwaysShow` เป็น `true` บนวิดเจ็ต และหากคุณสนใจแค่บางตัว ให้ระบุตัวที่ต้องการไว้ใน `items`: `["Dnd", "Reminder", "NightLight"]` คุณมีวิดเจ็ตตัวบ่งชี้ได้มากกว่าหนึ่งตัว ส่วนต่าง ๆ จึงแสดงชุดย่อยที่ต่างกันได้

## จัดแถบใหม่

แถบตั้งค่าตัวเองได้ คุณไม่จำเป็นต้องเปิดไฟล์การตั้งค่าเพื่อย้ายสิ่งต่าง ๆ

จับพื้นที่ว่างของแถบบริเวณตรงกลางแล้วลากไปยังขอบหน้าจอด้านอื่น แถบก็จะย้ายไปที่นั่น ซ้าย ขวา บน หรือล่าง ใช้ได้ทั้งหมด และวิดเจ็ตทุกตัวก็ปรับตัวตาม (แถบแนวตั้งจะถอยกลับไปเป็นรูปแบบกะทัดรัดที่มีเฉพาะไอคอน) การคลิกค้างไว้ก็เริ่มการลากแบบเดียวกัน ดับเบิลคลิกซ้ายบนพื้นที่ว่างเดียวกันนั้นเพื่อสลับพื้นหลังของแถบจากใสไปเป็นแบบแก้วไปเป็นแบบทึบ และลากวิดเจ็ตใดก็ได้เพื่อจัดลำดับใหม่หรือโยนเข้าไปในอีกส่วนหนึ่ง วิดเจ็ตอื่น ๆ จะเลื่อนแยกออกจากกันเพื่อเปิดที่ว่างตรงจุดที่มันจะลง

ตรงกลางของแถบคือกล่องหนึ่งกล่อง: อะไรก็ตามที่อยู่ในนั้นจะคงอยู่ตรงกลางเป็นกลุ่มเดียว และวิดเจ็ตที่อยู่สองข้างของมันจะห้อยอยู่ตามขอบของมัน ขณะที่คุณลากวิดเจ็ต กล่องจะแสดงเป็นเส้นขอบ หรือเป็นเส้นพาดผ่านแถบเมื่อกล่องว่างเปล่า และคุณวางลงในกล่องหรือข้างกล่องก็ได้ เมื่อการวางจะลงในกล่อง กล่องจะขยายออกเพื่อรับวิดเจ็ตเข้าไป

วิดเจ็ตที่คุณอยากให้อยู่ใกล้มือแต่ไม่ต้องอยู่ในสายตาตลอดเวลา สามารถเข้าไปอยู่ในลิ้นชักของถาดได้: ลากมันไปวางบนถาด และลิ้นชักจะเปิดออกเพื่อรับมันเข้าไป มันจะอยู่ตรงนั้นหลังไอคอนแอปต่าง ๆ ปรากฏขึ้นเมื่อใดก็ตามที่ลิ้นชักปรากฏ และจะคงลิ้นชักของตัวเองให้เปิดอยู่ขณะที่แผงของมันเปิดอยู่ ลากมันกลับออกมาบนแถบเพื่อนำกลับไปไว้ที่เดิม

หากคุณอยากเลือกจากเมนูมากกว่า **ลักษณะที่ปรากฏ → แถบเมนู** มีตัวเลือกตำแหน่ง และ **พื้นหลังของแถบ** ใช้เลือกวิธีวาดแถบ: **แถบแบบทึบ**, **แถบแบบแก้ว** (โปร่งใส โดยสิ่งที่อยู่ข้างหลังจะถูกเบลอ) หรือ **แถบแบบใส**

สิ่งเดียวกันเหล่านี้มีคำสั่งด้วย ซึ่งเป็นสิ่งที่คุณต้องการสำหรับการตั้งค่าแบบ [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

หากต้องการเพิ่มหรือลบวิดเจ็ตออกไปทั้งหมด ให้ใช้คำสั่งปลั๊กอิน `omarchy plugin list` จะพิมพ์วิดเจ็ตทุกตัวที่เชลล์รู้จักพร้อม id ของมัน จากนั้น:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## ซ่อนแถบ

`Super + Shift + Space` สลับแถบให้ปิดและกลับมาเปิดอีกครั้งโดยไม่ฆ่าเชลล์ แผงและปุ่มลัดยังคงทำงานต่อไป คุณแค่ได้พิกเซลกลับคืนมา นอกจากนี้ยังอยู่ในเมนูใต้ **ลักษณะที่ปรากฏ → แถบเมนู → ซ่อนแถบ** ด้วย

## ไฟล์การตั้งค่า

ทั้งหมดนี้ถูกเก็บไว้ใน `~/.config/omarchy/shell.json` ภายใต้คีย์ `bar` นี่คือเวอร์ชันที่ตัดให้สั้นลง:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

วิดเจ็ตทุกตัวคือหนึ่งรายการในหนึ่งในอาร์เรย์เลย์เอาต์ทั้งห้า และการตั้งค่าของมันอยู่แบบอินไลน์บนรายการนั้น ไม่มีไฟล์การตั้งค่าแยกต่างหาก และไม่มีออบเจ็กต์ย่อย `config` ค่า `format`, `formatAlt` (สิ่งที่การคลิกขวาจะสลับไปถึง) และ `verticalFormat` ของนาฬิกา ล้วนอยู่ตรงนั้นบน `{ "id": "omarchy.clock" }`

`center` คือกล่องที่อยู่ตรงกลางของแถบ: ทุกอย่างในนั้นจะอยู่ตรงกลางหน้าจอเป็นกลุ่มเดียว `centerBegin` และ `centerEnd` ห้อยอยู่สองข้างของกล่อง ซึ่งเป็นวิธีที่นาฬิกายังคงอยู่ตรงกลางพอดิบพอดีแม้สภาพอากาศและป้ายอัปเดตจะมาแล้วไป ใส่วิดเจ็ตมากกว่าหนึ่งตัวลงใน `center` แล้วพวกมันจะอยู่ตรงกลางด้วยกัน ปล่อยให้มันว่างไว้ แล้ว `centerBegin` และ `centerEnd` จะมาพบกันตรงกลางของแถบ

กฎข้อหนึ่งที่ควรซึมซับไว้: **เมื่อคุณมี `shell.json` ของตัวเองแล้ว ไฟล์นั้นถือเป็นหลัก** จนกว่าคุณจะปรับแต่งอะไร เชลล์จะอ่านไฟล์ค่าเริ่มต้นของ Omarchy ทันทีที่คุณลากวิดเจ็ต เรียกใช้ `omarchy bar` หรือแก้ไขไฟล์ด้วยตัวเอง คุณคือเจ้าของไฟล์นั้น ไม่มีการผสานเชิงลึก ดังนั้นวิดเจ็ตค่าเริ่มต้นใหม่ ๆ ใน Omarchy รุ่นถัดไปในอนาคตจะไม่ปรากฏบนแถบของคุณโดยอัตโนมัติ `omarchy bar defaults` จะนำเลย์เอาต์ที่มาพร้อมกับโปรแกรมกลับมาเมื่อใดก็ตามที่คุณต้องการเริ่มจากศูนย์

ไฟล์เดียวกันนี้ยังเก็บเวลารอขณะไม่มีการใช้งานของคุณไว้ที่ระดับบนสุด นอกคีย์ `bar` ด้วย: `idle.screensaver` และ `idle.lock` ทั้งคู่มีหน่วยเป็นวินาทีนับตั้งแต่คุณไม่มีการใช้งาน ดังนั้นโปรแกรมรักษาหน้าจอเริ่มต้นจะเริ่มทำงานที่ 150 วินาที และตัวล็อกจะเริ่มที่ 300 วินาที
