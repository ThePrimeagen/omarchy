# اوپر کا بار

آپ کی اسکرین کے اوپر والی پٹی Omarchy بار ہے۔ یہ کوئی اوپر سے چپکائی گئی اسٹیٹس بار نہیں ہے بلکہ Omarchy شیل کا حصہ ہے، وہی واحد دیرپا چلنے والا Quickshell پروسیس جو مینیو، اطلاعات، OSD پاپ اپس، اور لاک اسکرین بھی بناتا ہے۔ اسی لیے یہ ہر چیز کے ساتھ بالکل درست انداز میں تھیم ہوتا ہے اور اسی لیے کوئی پینل نئے ایپ کو شروع کرنے کے بجائے فوراً کھل جاتا ہے۔

یہ ڈیسک ٹاپ کا وہ واحد حصہ بھی ہے جو ہمیشہ اسکرین پر رہتا ہے، اس لیے یہ جاننا فائدہ مند ہے کہ وہ تمام چھوٹی چھوٹی علامات کیا کرتی ہیں۔

## ڈیفالٹ طور پر اس پر کیا ہوتا ہے

بار کے تین حصے ہیں۔ بائیں طرف Omarchy لوگو (مینیو لانچر) اور ورک اسپیس کے اشارے بیٹھے ہیں۔ درمیان میں آپ کو اسٹیٹس کے اشارے، گھڑی، Elsewhen (ایک عالمی گھڑی)، موسم، اور Omarchy اپ ڈیٹ بیج ملتا ہے۔ دائیں طرف: سسٹم ٹرے، کی بورڈ لے آؤٹ (جب ایک سے زیادہ لے آؤٹ یا ان پٹ طریقہ ترتیب دیا گیا ہو)، ایجنٹس، bluetooth، نیٹ ورک، آڈیو، ڈسپلے، اور پاور۔

ان میں سے چند ہی صرف اس وقت نظر آتے ہیں جب ان کے پاس کہنے کو کچھ ہو۔ کی بورڈ لے آؤٹ صرف اسی وقت ظاہر ہوتا ہے جب آپ نے ایک سے زیادہ لے آؤٹ یا ان پٹ طریقہ ترتیب دیا ہو۔ اپ ڈیٹ بیج صرف اسی وقت ظاہر ہوتا ہے جب کوئی Omarchy اپ ڈیٹ منتظر ہو۔

## پینلز

بار کے آئیکن پر کلک کرنے سے ایک پینل کھلتا ہے، جو ٹول ٹپ کے بجائے سلائیڈرز، فہرستوں، اور کی بورڈ نیویگیشن کے ساتھ ایک باقاعدہ پاپ اپ ہوتا ہے۔ ہر ایک کی ایک ہاٹ کی بھی ہے، تاکہ آپ کو کبھی 16-پکسل علامت پر نشانہ نہ باندھنا پڑے:

| ہاٹ کی | پینل |
| --- | --- |
| `Super + Ctrl + A` | آڈیو |
| `Super + Ctrl + N` | نیٹ ورک |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | ڈسپلے |
| `Super + Ctrl + P` | پاور |
| `Super + Ctrl + Alt + D` | کیلنڈر |
| `Super + Ctrl + Alt + E` | عالمی گھڑی |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | دائیں حصے میں ویں نمبر کے پینل کو ٹوگل کریں |

پینلز صرف ریڈ آؤٹس نہیں ہیں۔ یہ وہ جگہ ہیں جہاں آپ اصل میں کام کرتے ہیں:

- **آڈیو** میں ایک ماسٹر آواز سلائیڈر، ایک آؤٹ پٹ ڈیوائس منتخب کنندہ، اور فی ایپ مکسچر ہے، تاکہ آپ باقی ہر چیز کو چھوئے بغیر اس ایک براؤزر ٹیب کی آواز کم کر سکیں۔
- **نیٹ ورک** Wi-Fi کے لیے اسکین کرتا ہے، سگنل کی طاقت دکھاتا ہے، منسلک ہوتا ہے، اور آپ کو DNS فراہم کنندہ منتخب کرنے دیتا ہے۔
- **Bluetooth** آپ کے آلات کو منسلک/منقطع اور بیٹری کی سطح کے ساتھ فہرست کرتا ہے۔
- **پاور** بیٹری کے اعداد و شمار دکھاتا ہے، پاور پروفائلز بدلتا ہے (یہ بیٹری اور AC کے لیے الگ انتخاب یاد رکھتا ہے)، اور کچھ سسٹم معلومات چھاپتا ہے۔
- **ڈسپلے** میں چمک کا سلائیڈر، متن کا سائز، مانیٹر اسکیلنگ پری سیٹس، اور — جب آپ کے پاس ایک سے زیادہ اسکرین ہو — فی مانیٹر کنٹرولز ہوتے ہیں۔ گہری کہانی کے لیے [مانیٹرز](33-monitors.md) دیکھیں۔
- **گھڑی** ISO ہفتہ نمبروں اور مہینہ آگے پیچھے کرنے کے ساتھ ایک مہینے کا گرڈ کھولتی ہے۔
- **عالمی گھڑی** ہر شہر کے لیے ایک قطار رکھتی ہے، اس کے موسم اور اس کے دن کے گزرنے کے انداز کے ساتھ۔ تلاش قصبوں کو بھی ڈھونڈتی ہے اور ساتھ ہی ٹائم زونز کو بھی، اس لیے Fort Lauderdale، Fort Lauderdale ہی ہے نہ کہ New York۔ اگر سب سے اوپر والی سطر غلط شہر کا نام بتائے تو اس پر کلک کریں اور بتائیں کہ آپ کہاں ہیں؛ کسی دوسرے ٹائم زون پر کوئی جگہ چنیں اور سسٹم گھڑی بھی وہاں منتقل ہو جاتی ہے، جو سفر کے دوران کارآمد ہے۔ کسی شہر پر ہوور کریں اور فرد والے بٹن پر کلک کر کے بتائیں کہ وہاں کون رہتا ہے — سادہ نام، یا `@` GitHub ہینڈلز تاکہ ان کے چہرے بھی ساتھ آ جائیں۔

ہر پینل ماؤس کے ساتھ ساتھ کی بورڈ بھی لیتا ہے: تیر حرکت کرتے ہیں، Return فعال کرتا ہے، Tab پڑوسی پینل کی طرف قدم بڑھاتا ہے، اور Escape بند کرتا ہے۔

`Super + Ctrl + 1-9` دائیں حصے میں پینلز کو بائیں سے دائیں گنتا ہے، ٹرے کو چھوڑ کر کیونکہ اس کا اپنا کوئی پینل نہیں ہے۔ اس لیے نمبر اس آئیکن سے میل کھاتا ہے جس کی طرف آپ اشارہ کریں گے۔

### Tailscale اور Dropbox

دو مزید وجٹس بار پر صرف اسی وقت ظاہر ہوتے ہیں جب آپ **Install → Service** سے متعلقہ سروس انسٹال کرتے ہیں، اور دونوں کو جاننا فائدہ مند ہے کیونکہ یہ صرف اسٹیٹس بتانے سے زیادہ کرتے ہیں۔

**Tailscale** پینل ٹیل نیٹ کو منسلک اور منقطع کرتا ہے، کھاتوں کے درمیان بدلتا ہے، اور ایک ایگزٹ نوڈ چنتا ہے (آپ کی اپنی مشینیں اور Mullvad خطے دونوں اس فہرست میں ظاہر ہوتے ہیں)۔ یہ آپ کی مشینوں کو بھی براؤز کرتا ہے — اور ایک منتخب ہونے کے ساتھ، `s` Taildrop کے ذریعے فائلیں اسے بھیجتا ہے، جو فائل کو آپ کے فون یا کسی دوسرے لیپ ٹاپ تک منتقل کرنے کا تیز ترین طریقہ ہے۔ `c` مشین کا IP کاپی کرتا ہے، `n` اس کا نام، اور `d` اس کا مکمل DNS نام۔ ہر مشین کی قطار پر ایک بھیجنے کا بٹن بھی ہے، اگر آپ اس کے بجائے کلک کرنا پسند کریں۔ ٹرمینل سے یہی چیز `omarchy tailscale send <machine> [file...]` ہے۔

**Dropbox** پینل لاگ ان سنبھالتا ہے، دکھاتا ہے کہ آپ نے کتنی اسٹوریج استعمال کی ہے، اور حال ہی میں ہم آہنگ شدہ فائلوں کی فہرست دیتا ہے۔

کسی بھی سروس کو ہٹانے سے اس کا وجٹ بار سے واپس ہٹ جاتا ہے۔

## اشارے

درمیان میں موجود چھوٹا سا جھرمٹ اشاروں کا وجٹ ہے۔ یہ ان موڈز کے لیے اسٹیٹس علامات ہیں جنہیں آپ نے آن کیا ہے: ڈسٹرب نہ کریں، رات کی روشنی، ایک قطار میں لگا [یاددہانی](09-reminders.md)، ایک فعال اسکرین ریکارڈنگ، اور بیدار رہیں، اس کے علاوہ انتباہات جب کہ پاس ورڈ کے بغیر sudo آن ہو یا کوئی ریموٹ سیشن سے منسلک ہو۔ یہ اس وقت روشن ہوتے ہیں جب موڈ فعال ہو اور ورنہ راستے سے ہٹے رہتے ہیں — ان کے بالکل پاس ہوور کریں، جہاں غیر فعال والے بیٹھے ہوں گے، ان کی جھلک دیکھنے کے لیے۔ کسی اشارے پر کلک کرنے سے وہ موڈ ٹوگل ہو جاتا ہے۔ ایک اور صرف اسٹیٹس کے لیے ہے: ایک ریموٹ سیشن اس وقت سرخ روشن ہوتا ہے جب کوئی gliff کے ذریعے اس مشین سے منسلک ہو۔

اگر آپ چاہتے ہیں کہ یہ ہمیشہ دکھائی دیں تو وجٹ پر `alwaysShow` کو `true` پر مقرر کریں۔ اور اگر آپ کو ان میں سے صرف چند کی پرواہ ہے تو جنہیں آپ چاہتے ہیں انہیں `items` میں درج کریں: `["Dnd", "Reminder", "NightLight"]`۔ آپ کے پاس ایک سے زیادہ اشاروں کے وجٹس ہو سکتے ہیں، تاکہ مختلف حصے مختلف ذیلی سیٹ دکھا سکیں۔

## بار کو دوبارہ ترتیب دینا

بار خود کو ترتیب دیتا ہے۔ چیزوں کو منتقل کرنے کے لیے آپ کو کوئی کانفیگ فائل کھولنے کی ضرورت نہیں ہے۔

درمیان کے آس پاس بار کے خالی حصے کو پکڑیں اور اسے اسکرین کے کسی اور کنارے کی طرف گھسیٹیں، اور بار وہاں منتقل ہو جاتا ہے — بائیں، دائیں، اوپر، یا نیچے سب کام کرتے ہیں، اور ہر وجٹ ڈھل جاتا ہے (عمودی بارز مختصر صرف آئیکن والی شکلوں پر واپس آ جاتے ہیں)۔ کلک اور پکڑے رہنا بھی یہی گھسیٹنا شروع کرتا ہے۔ اسی خالی جگہ پر ڈبل بایاں کلک کر کے بار کے پس منظر کو صاف سے شیشے جیسا اور مبہم میں سائیکل کریں۔ اور کسی بھی وجٹ کو گھسیٹ کر اسے دوبارہ ترتیب دیں یا اسے کسی اور حصے میں پھینک دیں؛ دوسرے وجٹس الگ ہو جاتے ہیں تاکہ وہاں جگہ بن جائے جہاں یہ اترے گا۔

بار کا درمیان ایک ڈبہ ہے: اس میں جو کچھ بھی ہے وہ ایک گروپ کے طور پر درمیان میں رہتا ہے، اور اس کے دونوں طرف کے وجٹس اس کے کناروں سے لٹکتے ہیں۔ جب آپ کوئی وجٹ گھسیٹتے ہیں تو ڈبہ ایک خاکے کے طور پر دکھائی دیتا ہے، یا جب یہ خالی ہو تو بار کے پار ایک سطر کے طور پر، اور آپ اس میں یا اس کے پاس چھوڑ سکتے ہیں۔ جب کوئی چھوڑنا ڈبے میں اترنے والا ہو تو ڈبہ وجٹ کو اندر لینے کے لیے بڑھ جاتا ہے۔

کوئی وجٹ جسے آپ ارد گرد رکھنا چاہتے ہیں لیکن ہمیشہ نظر میں نہیں، وہ ٹرے کی دراز میں جا سکتا ہے: اسے ٹرے پر گھسیٹیں، اور دراز اسے لینے کے لیے کھل جاتی ہے۔ یہ وہاں ایپ آئیکنز کے بعد بیٹھتا ہے، جب بھی دراز آتی ہے تب ظاہر ہوتا ہے، اور جب اس کا پینل اوپر ہو تو اپنی دراز کو کھلا رکھتا ہے۔ اسے واپس بار پر گھسیٹ کر باہر نکالیں تاکہ یہ واپس آ جائے۔

اگر آپ اس کے بجائے مینیو سے منتخب کرنا پسند کریں تو **Appearance → Menu Bar** کے پاس مقام ہے، اور **Bar Background** منتخب کرتا ہے کہ بار کیسے بنایا جائے: **Opaque Bar**، **Glassy Bar** (شفاف، اس کے پیچھے جو ہے وہ دھندلا ہوا)، یا **Clear Bar**۔

انہی چیزوں کے کمانڈز بھی ہیں، جو آپ [dotfiles](31-dotfiles.md) سیٹ اپ کے لیے چاہتے ہیں:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## بار کو چھپانا

`Super + Shift + Space` شیل کو ختم کیے بغیر بار کو بند اور واپس آن کرتا ہے — پینلز اور ہاٹ کیز کام کرتی رہتی ہیں، آپ کو بس پکسلز واپس مل جاتے ہیں۔ یہ مینیو میں **Appearance → Menu Bar → Hide Bar** کے تحت بھی ہے۔

## کانفیگ فائل

یہ سب `~/.config/omarchy/shell.json` میں، `bar` کلید کے تحت محفوظ ہے۔ یہ رہا ایک مختصر شدہ ورژن:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

ہر وجٹ پانچ لے آؤٹ ارے میں سے کسی ایک میں ایک اندراج ہے، اور اس کی ترتیبات اسی اندراج پر ان لائن بیٹھتی ہیں — کوئی الگ ترتیبات فائل نہیں ہے اور کوئی `config` ذیلی آبجیکٹ نہیں ہے۔ گھڑی کا `format`، `formatAlt` (جس پر دایاں کلک سائیکل کرتا ہے)، اور `verticalFormat` سب وہیں `{ "id": "omarchy.clock" }` پر رہتے ہیں۔

`center` بار کے درمیان میں ڈبہ ہے: اس میں موجود ہر چیز اسکرین پر ایک گروپ کے طور پر درمیان میں ہوتی ہے۔ `centerBegin` اور `centerEnd` ڈبے کے دونوں طرف لٹکتے ہیں، یہی طریقہ ہے کہ گھڑی بالکل درمیان میں رہتی ہے چاہے موسم اور اپ ڈیٹ بیج آتے جاتے رہیں۔ `center` میں ایک سے زیادہ وجٹ رکھیں اور وہ ایک ساتھ درمیان میں ہوتے ہیں؛ اسے خالی چھوڑیں اور `centerBegin` اور `centerEnd` بار کے درمیان میں مل جاتے ہیں۔

ایک اصول جسے ذہن نشین کرنا فائدہ مند ہے: **ایک بار جب آپ کے پاس اپنی `shell.json` ہو جائے تو یہی مستند ہے**۔ جب تک آپ کچھ بھی حسب ضرورت نہ بنائیں، شیل Omarchy کی ڈیفالٹ فائل پڑھتا ہے۔ جس لمحے آپ کوئی وجٹ گھسیٹتے ہیں، `omarchy bar` چلاتے ہیں، یا فائل خود ترمیم کرتے ہیں، آپ اس کے مالک ہیں — کوئی گہرا ضم نہیں ہے، اس لیے مستقبل کی Omarchy ریلیزز میں نئے ڈیفالٹ وجٹس خود بخود آپ کے بار پر ظاہر نہیں ہوں گے۔ `omarchy bar defaults` بھیجا گیا لے آؤٹ واپس رکھ دیتا ہے جب بھی آپ صاف سلیٹ چاہیں۔

یہی فائل آپ کے غیر فعال اوقات کو بھی اعلیٰ سطح پر، `bar` کلید کے باہر رکھتی ہے: `idle.screensaver` اور `idle.lock`، دونوں ان سیکنڈز میں جب سے آپ غیر فعال ہوئے۔ اس لیے ڈیفالٹ اسکرین سیور 150 سیکنڈ پر شروع ہوتا ہے اور لاک 300 پر۔
