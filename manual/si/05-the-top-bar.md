# ඉහළ තීරුව

ඔබේ තිරයේ ඉහළින් ඇති තීරුව Omarchy තීරුවයි. එය බෝල්ට් කර සවිකළ තත්ත්ව තීරුවක් නොව Omarchy shell එකේම කොටසකි, එනම් මෙනුව, දැනුම්දීම්, OSD popups සහ lock screen එකද අඳින තනි, දිගු කාලයක් ක්‍රියාත්මක වන Quickshell process එකමය. ඒ නිසාම එය අනෙක් සියල්ල සමඟම පරිපූර්ණව තේමා වන අතර, අලුත් app එකක් spawn කරනවා වෙනුවට panel එකක් ක්ෂණිකව විවෘත වන්නේද ඒ නිසාමය.

එය desktop එකේ නිතරම තිරයේ පවතින එකම කොටසද වන බැවින්, ඒ කුඩා glyphs සියල්ල කරන්නේ කුමක්දැයි දැන සිටීම වටී.

## පෙරනිමියෙන් එහි ඇත්තේ මොනවාද

තීරුවට කොටස් තුනක් ඇත. වම් පසින් Omarchy ලාංඡනය (මෙනු දියත්කරකය) සහ workspace දර්ශක පිහිටා ඇත. මැදින් ඔබට තත්ත්ව දර්ශක, ඔරලෝසුව, Elsewhen (ලෝක ඔරලෝසුවක්), කාලගුණය සහ Omarchy යාවත්කාලීන ලාංඡනය ලැබේ. දකුණු පසින්: system tray එක, යතුරුපුවරු පිරිසැලසුම (පිරිසැලසුම් එකකට වඩා හෝ ආදාන ක්‍රමයක් වින්‍යාස කර ඇති විට), agents, bluetooth, ජාලය, ශ්‍රව්‍ය, සංදර්ශකය සහ බලය.

ඒවායින් කිහිපයක් පෙන්වන්නේ ඒවාට කීමට යමක් ඇති විට පමණි. යතුරුපුවරු පිරිසැලසුම පෙන්වන්නේ ඔබ පිරිසැලසුම් එකකට වඩා හෝ ආදාන ක්‍රමයක් වින්‍යාස කර ඇත්නම් පමණි. යාවත්කාලීන ලාංඡනය පෙන්වන්නේ Omarchy යාවත්කාලීනයක් බලාපොරොත්තුවෙන් ඇති විට පමණි.

## Panels

තීරු නිරූපකයක් ක්ලික් කිරීමෙන් panel එකක් විවෘත වේ, එය tooltip එකක් වෙනුවට sliders, ලැයිස්තු සහ යතුරුපුවරු සංචාලනය සහිත නිසි popup එකකි. සෑම එකකටම hotkey එකක්ද ඇත, එබැවින් ඔබට කිසිවිට pixel 16ක glyph එකක් ඉලක්ක කිරීමට සිදු නොවේ:

| Hotkey | Panel |
| --- | --- |
| `Super + Ctrl + A` | ශ්‍රව්‍ය |
| `Super + Ctrl + N` | ජාලය |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | සංදර්ශකය |
| `Super + Ctrl + P` | බලය |
| `Super + Ctrl + Alt + D` | දිනදර්ශනය |
| `Super + Ctrl + Alt + E` | ලෝක ඔරලෝසුව |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | දකුණු කොටසේ nවන panel එක මාරු කරන්න |

Panels යනු කියවීම් පමණක් නොවේ. ඔබ ඇත්තටම දේ කරන්නේ ඒවා තුළිනි:

- **ශ්‍රව්‍ය** සතුව ප්‍රධාන ශබ්ද ප්‍රමාණ slider එකක්, ප්‍රතිදාන උපාංග තේරීම්කරකයක් සහ app එක බැගින් mixer එකක් ඇත, එබැවින් අනෙක් සියල්ල ස්පර්ශ නොකරම ඔබට එම එක් browser පටිත්ත අඩු කළ හැක.
- **ජාලය** Wi-Fi සඳහා scan කරයි, සංඥා ශක්තිය පෙන්වයි, සම්බන්ධ වේ, සහ DNS සපයන්නෙකු තෝරා ගැනීමට ඔබට ඉඩ දෙයි.
- **Bluetooth** ඔබේ උපාංග සම්බන්ධ/විසන්ධි කිරීම සහ බැටරි මට්ටම් සමඟ ලැයිස්තුගත කරයි.
- **බලය** බැටරි සංඛ්‍යාලේඛන පෙන්වයි, බල පැතිකඩ මාරු කරයි (එය බැටරිය සහ AC සඳහා වෙනම තේරීමක් මතක තබා ගනී), සහ යම් පද්ධති තොරතුරු මුද්‍රණය කරයි.
- **සංදර්ශකය** සතුව දීප්ති slider එකක්, අකුරු ප්‍රමාණය, මොනිටර පරිමාණ පෙරසිටුවීම්, සහ — ඔබට තිර එකකට වඩා ඇති විට — මොනිටරය බැගින් පාලන ඇත. ගැඹුරු කතාව සඳහා [මොනිටර](33-monitors.md) බලන්න.
- **ඔරලෝසුව** ISO සති අංක සහ මාස පියවර සහිත මාස ජාලයක් විවෘත කරයි.
- **ලෝක ඔරලෝසුව** නගරය බැගින් පේළියක් තබයි, එහි කාලගුණය සහ එහි දවස ගෙවී යන ආකාරය සමඟ. Search මඟින් වේලා කලාප මෙන්ම නගරද සොයා ගනී, එබැවින් Fort Lauderdale යනු Fort Lauderdale මිස New York නොවේ. ඉහළින් ඇති පේළිය වැරදි නගරයක් නම් කරන්නේ නම්, එය ක්ලික් කර ඔබ සිටින තැන කියන්න; වෙනත් වේලා කලාපයක තැනක් තෝරන්න, පද්ධති ඔරලෝසුවද එහිට ගමන් කරයි, ඔබ ගමන් කරන විට එය පහසුය. නගරයක් මත hover කර එහි වෙසෙන්නේ කවුරුන්දැයි කීමට person බොත්තම ක්ලික් කරන්න — සරල නම්, හෝ ඔවුන්ගේ මුහුණුද සමඟ ගෙන ඒමට `@` GitHub handles.

සෑම panel එකක්ම මූසිකය මෙන්ම යතුරුපුවරුවද ගනී: ඊතල ගමන් කරයි, Return සක්‍රිය කරයි, Tab අසල්වැසි panel එකට පියවර ගනී, සහ Escape වසයි.

`Super + Ctrl + 1-9` මඟින් දකුණු කොටසේ වමේ සිට දකුණට panels ගණන් කරයි, tray එකට තමන්ගේම panel එකක් නැති බැවින් එය මඟහරියි. එබැවින් අංකය ඔබ යොමු කරන නිරූපකයට ගැළපේ.

### Tailscale සහ Dropbox

ඔබ **Install → Service** වෙතින් ගැළපෙන සේවාව ස්ථාපනය කළ පසු තවත් widgets දෙකක් තීරුවේ පෙන්වන අතර, ඒ දෙකම තත්ත්වය වාර්තා කිරීමට වඩා වැඩි යමක් කරන බැවින් ඒවා ගැන දැන සිටීම වටී.

**Tailscale** panel එක tailnet එක සම්බන්ධ කර විසන්ධි කරයි, ගිණුම් අතර මාරු වේ, සහ පිටත්වීමේ නෝඩයක් තෝරා ගනී (ඔබේම යන්ත්‍ර සහ Mullvad කලාප දෙකම එම ලැයිස්තුවේ පෙන්වයි). එය ඔබේ යන්ත්‍රද බ්‍රවුස් කරයි — එකක් තෝරාගත් පසු, `s` මඟින් Taildrop හරහා එයට ගොනු යවයි, එය ඔබේ දුරකථනයට හෝ වෙනත් laptop එකකට ගොනුවක් ගෙන යාමට ඇති වේගවත්ම ක්‍රමයයි. `c` මඟින් යන්ත්‍රයේ IP එක පිටපත් කරයි, `n` එහි නම, සහ `d` එහි සම්පූර්ණ DNS නම. ඔබට ක්ලික් කිරීමට අවශ්‍ය නම් සෑම යන්ත්‍ර පේළියකම send බොත්තමක්ද ඇත. terminal එකෙන් එම දෙයම `omarchy tailscale send <machine> [file...]` වේ.

**Dropbox** panel එක login වීම හසුරුවයි, ඔබ කොපමණ ගබඩාවක් භාවිත කර ඇත්දැයි පෙන්වයි, සහ මෑතකදී සමමුහුර්ත කළ ගොනු ලැයිස්තුගත කරයි.

සේවා දෙකෙන් එකක් ඉවත් කිරීමෙන් එහි widget එක නැවත තීරුවෙන් ඉවත් වේ.

## දර්ශක

මැද ඇති කුඩා පොකුර indicators widget එකයි. මේවා ඔබ ක්‍රියාත්මක කර ඇති ක්‍රම සඳහා වූ තත්ත්ව glyphs ය: බාධා නොකරන්න, රාත්‍රී ආලෝකය, පෝලිමේ ඇති [උපදේශනයක්](09-reminders.md), සක්‍රිය තිර පටිගත කිරීමක්, සහ අවදියෙන් සිටීම, තවද මුරපද රහිත sudo ක්‍රියාත්මක වන විට හෝ යමෙකු දුරස්ථ සැසියකට සම්බන්ධ වී ඇති විට අනතුරු ඇඟවීම්ද ඇත. ක්‍රමය සක්‍රිය වන විට ඒවා දැල්වෙන අතර එසේ නොමැති විට මගහැර සිටී — අක්‍රිය ඒවා පිහිටා තිබිය හැකි තැනට, ඒවාට යාබදව hover කර ඒවා දෙස බලන්න. දර්ශකයක් ක්ලික් කිරීමෙන් එම ක්‍රමය මාරු වේ. තවත් එකක් තත්ත්වය පමණක්මය: යමෙකු gliff හරහා මෙම යන්ත්‍රයට සම්බන්ධ වී සිටින විට දුරස්ථ සැසියක් රතු පැහැයෙන් දැල්වේ.

ඔබ කැමති නම් ඒවා සැමවිටම දෘශ්‍යමානව තැබීමට, widget එකේ `alwaysShow` අගය `true` ලෙස සකසන්න. තවද ඔබ සැලකිලිමත් වන්නේ ඒවායින් සමහරක් ගැන පමණක් නම්, ඔබට අවශ්‍ය ඒවා `items` හි ලැයිස්තුගත කරන්න: `["Dnd", "Reminder", "NightLight"]`. ඔබට indicators widgets එකකට වඩා තිබිය හැක, එබැවින් විවිධ කොටස්වලට විවිධ උපකුලක පෙන්විය හැක.

## තීරුව නැවත සකස් කිරීම

තීරුව තමන් විසින්ම වින්‍යාස වේ. දේවල් ගෙන යාමට ඔබට config ගොනුවක් විවෘත කිරීමට සිදු නොවේ.

මැද වටා තීරුවේ හිස් කොටසක් අල්ලා වෙනත් තිර දාරයක් දෙසට එය අදින්න, තීරුව එහිට ගමන් කරයි — වම, දකුණ, ඉහළ, හෝ පහළ සියල්ල ක්‍රියාත්මක වන අතර, සෑම widget එකක්ම එයට හැඩගැසේ (සිරස් තීරු සංයුක්ත නිරූපක-පමණක් ආකාරවලට ආපසු වැටේ). ක්ලික් කර අල්ලාගෙන සිටීමෙන්ද එම ඇදීමම ආරම්භ වේ. එම හිස් ඉඩම දෙවරක් වම්-ක්ලික් කර තීරු පසුබිම පැහැදිලි සිට වීදුරුමය සිට පාරාන්ධ දක්වා මාරු කරන්න. තවද ඕනෑම widget එකක් එය නැවත සකස් කිරීමට හෝ වෙනත් කොටසකට විසි කිරීමට අදින්න; අනෙක් widgets එය ගොඩබසින තැන ඉඩ සෑදීමට ලිස්සා ඈත් වේ.

තීරුවේ මැද පෙට්ටියකි: එහි ඇති ඕනෑම දෙයක් එක් කණ්ඩායමක් ලෙස මැදෙහිම සිටින අතර, එහි දෙපස ඇති widgets එහි දාරවලින් එල්ලී සිටී. ඔබ widget එකක් අදින අතරතුර පෙට්ටිය දළ සටහනක් ලෙස පෙන්වයි, නැතහොත් එය හිස් වූ විට තීරුව හරහා රේඛාවක් ලෙස පෙන්වයි, ඔබට එයට හෝ එය අසලට වැටිය හැක. වැටීමක් පෙට්ටියට ගොඩබැසීමට තිබේ නම්, පෙට්ටිය widget එක ඇතුළට ගැනීමට විශාල වේ.

ඔබට අවට තබා ගැනීමට අවශ්‍ය නමුත් නිතරම පෙනෙන්නට අවශ්‍ය නොවන widget එකක් tray එකේ drawer එකට යා හැක: එය tray එක මතට අදින්න, drawer එක එය ගැනීමට විවෘත වේ. එය app නිරූපකවලින් පසුව එහි සිටී, drawer එක පෙන්වන සෑම විටම පෙන්වයි, සහ එහි panel එක ඉහළින් ඇති අතරතුර එහි drawer එක විවෘතව තබා ගනී. එය නැවත තැබීමට එය නැවත තීරුව මතට අදින්න.

ඔබ මෙනුවකින් තෝරා ගැනීමට කැමති නම්, **Appearance → Menu Bar** සතුව පිහිටීම ඇත, **Bar Background** මඟින් තීරුව අඳින ආකාරය තෝරයි: **Opaque Bar**, **Glassy Bar** (පසුවිට ඇති දෙය නොපැහැදිලි කර ඇති, විනිවිද පෙනෙන), හෝ **Clear Bar**.

එම දේවල්ටම commands ඇත, එය [dotfiles](31-dotfiles.md) සැකසුමක් සඳහා ඔබට අවශ්‍ය දෙයයි:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

widget එකක් සම්පූර්ණයෙන්ම එක් කිරීමට හෝ ඉවත් කිරීමට, plugin commands භාවිත කරන්න. `omarchy plugin list` මඟින් shell එක දන්නා සෑම widget එකක්ම එහි id එක සමඟ මුද්‍රණය කරන අතර, ඉන්පසුව:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## තීරුව සැඟවීම

`Super + Shift + Space` මඟින් shell එක නොමරා තීරුව අක්‍රිය කර නැවත ක්‍රියාත්මක කරයි — panels සහ hotkeys දිගටම ක්‍රියාත්මක වන අතර, ඔබට pixels නැවත ලැබෙනවා පමණි. එය මෙනුවේ **Appearance → Menu Bar → Hide Bar** යටතේද ඇත.

## Config ගොනුව

ඒ සියල්ල `~/.config/omarchy/shell.json` හි, `bar` යතුර යටතේ ගබඩා කර ඇත. මෙන්න කප්පාදු කළ අනුවාදයක්:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

සෑම widget එකක්ම පිරිසැලසුම් අරා පහෙන් එකක එක් ප්‍රවේශයක් වන අතර, එහි සිටුවම් එම ප්‍රවේශයේම ඇතුළත්ව පිහිටා ඇත — වෙනම සිටුවම් ගොනුවක් නැත, `config` උප-වස්තුවක්ද නැත. ඔරලෝසුවේ `format`, `formatAlt` (දකුණු-ක්ලික් කිරීමෙන් මාරු වන්නේ කුමක් වෙතද), සහ `verticalFormat` සියල්ල එහිම `{ "id": "omarchy.clock" }` මත ජීවත් වේ.

`center` යනු තීරුවේ මැද ඇති පෙට්ටියයි: එහි ඇති සියල්ල තිරයේ එක් කණ්ඩායමක් ලෙස මැදෙහි පිහිටුවා ඇත. `centerBegin` සහ `centerEnd` පෙට්ටියේ දෙපසින් එල්ලී සිටින අතර, කාලගුණය සහ යාවත්කාලීන ලාංඡනය එන යන විට පවා ඔරලෝසුව හරියටම මැදෙහි සිටින්නේ එලෙසිනි. `center` හි widgets එකකට වඩා තබන්න, ඒවා එකට මැදෙහි පිහිටයි; එය හිස්ව තබන්න, `centerBegin` සහ `centerEnd` තීරුවේ මැදදී හමුවේ.

ඇතුළට ගත යුතු එක නීතියක්: **ඔබටම අයත් `shell.json` එකක් ඔබට ලැබුණු පසු, එය තීරණාත්මකය**. ඔබ කිසිවක් අභිරුචිකරණය කරන තෙක්, shell එක Omarchy හි පෙරනිමි ගොනුව කියවයි. ඔබ widget එකක් අදින, `omarchy bar` ක්‍රියාත්මක කරන, හෝ ඔබම ගොනුව සංස්කරණය කරන මොහොතේ, එය ඔබ සතුය — ගැඹුරු සංයෝජනයක් නැත, එබැවින් අනාගත Omarchy නිකුතුන්හි අලුත් පෙරනිමි widgets ඔබේ තීරුවේ ස්වයංක්‍රීයව නොපෙන්වනු ඇත. ඔබට පිරිසිදු අරඹයක් අවශ්‍ය ඕනෑම විටක `omarchy bar defaults` මඟින් නැව්ගත කළ පිරිසැලසුම නැවත තබයි.

එම ගොනුවම ඉහළ මට්ටමේ, `bar` යතුරෙන් පිටත ඔබේ නිෂ්ක්‍රිය කාලයන්ද තබයි: `idle.screensaver` සහ `idle.lock`, දෙකම ඔබ නිෂ්ක්‍රිය වූ පසු තත්පර වලින්. එබැවින් පෙරනිමි screensaver එක තත්පර 150දී ක්‍රියාත්මක වන අතර lock එක තත්පර 300දී ක්‍රියාත්මක වේ.
