# टॉप बार

आपकी स्क्रीन के ऊपर की पट्टी Omarchy बार है। यह कोई अलग से जोड़ा गया status bar नहीं है, बल्कि Omarchy shell का हिस्सा है — वही एकल, लंबे समय तक चलने वाली Quickshell प्रक्रिया जो menu, notifications, OSD popups और lock screen भी बनाती है। इसीलिए यह बाकी सब चीज़ों के साथ पूरी तरह theme करता है और इसीलिए कोई panel किसी नए app को spawn करने के बजाय तुरंत खुलता है।

यह desktop का वह एकमात्र हिस्सा भी है जो हमेशा स्क्रीन पर रहता है, इसलिए यह जानना फ़ायदेमंद है कि वे सभी छोटे-छोटे glyphs क्या करते हैं।

## डिफ़ॉल्ट रूप से इस पर क्या होता है

बार के तीन खंड होते हैं। बाईं ओर Omarchy लोगो (menu launcher) और वर्कस्पेस संकेतक रहते हैं। बीच में आपको status संकेतक, घड़ी, Elsewhen (एक वर्ल्ड क्लॉक), मौसम और एक Omarchy अपडेट बैज मिलता है। दाईं ओर: system tray, keyboard layout (जब एक से अधिक layout या input method कॉन्फ़िगर किया गया हो), agents, ब्लूटूथ, नेटवर्क, ऑडियो, डिस्प्ले और पावर।

इनमें से कुछ केवल तभी दिखाई देते हैं जब उनके पास कहने के लिए कुछ हो। keyboard layout केवल तभी दिखाई देता है यदि आपने एक से अधिक layout या input method कॉन्फ़िगर किया हो। अपडेट बैज केवल तभी दिखाई देता है जब कोई Omarchy अपडेट प्रतीक्षा में हो।

## इधर-उधर क्लिक करना

लगभग हर विजेट बाएँ, दाएँ और मध्य क्लिक पर कुछ करता है, और कई स्क्रॉल करने पर भी प्रतिक्रिया देते हैं। यही वह हिस्सा है जो लोग चूक जाते हैं — दाएँ और मध्य बटन ही वह जगह हैं जहाँ बहुत-सी अच्छी चीज़ें छिपी होती हैं।

| विजेट | बायाँ | दायाँ | मध्य / स्क्रॉल |
| --- | --- | --- | --- |
| मेनू | Omarchy मेनू | नया terminal | — |
| वर्कस्पेस | इस मॉनिटर पर उस वर्कस्पेस पर फ़ोकस करें | — | स्क्रॉल: अगला/पिछला वर्कस्पेस |
| घड़ी | Calendar पॉपअप | लेबल प्रारूप बदलें | मध्य: timezone picker |
| वर्ल्ड क्लॉक | वर्ल्ड क्लॉक पैनल | रिफ़्रेश करें | मध्य: रिफ़्रेश |
| मौसम | पूर्वानुमान पॉपअप | notification के रूप में पूरा मौसम | मध्य: रिफ़्रेश |
| ऑडियो | ऑडियो पैनल | म्यूट करें | मध्य: पैनल · स्क्रॉल: वॉल्यूम |
| माइक्रोफ़ोन | माइक को म्यूट करें | — | मध्य: ऑडियो पैनल · स्क्रॉल: input वॉल्यूम |
| नेटवर्क | नेटवर्क पैनल | — | — |
| ब्लूटूथ | ब्लूटूथ पैनल | रेडियो टॉगल करें | — |
| डिस्प्ले | डिस्प्ले पैनल | — | स्क्रॉल: चमक |
| पावर | पावर पैनल | बैटरी प्रतिशत टॉगल करें | — |
| मीडिया | चलाएँ/रोकें | कवर-आर्ट पॉपअप | मध्य: अगला · स्क्रॉल: पिछला/अगला |
| Agents | Agents पैनल | अपना agent लॉन्च करें | मध्य: उपयोग रिफ़्रेश करें |
| ट्रे | दराज़ दिखाने के लिए होवर करें | प्रबंधित करने के लिए शेवरॉन पर दायाँ क्लिक करें | — |
| Omarchy अपडेट | अपडेट चलाएँ | — | — |

उस तालिका में सब कुछ आपकी बार पर शुरू से मौजूद नहीं होता। मीडिया विजेट (MPRIS now-playing, स्क्रॉल होते ट्रैक और कलाकार के साथ) और माइक्रोफ़ोन विजेट दोनों पहले से बने हुए हैं लेकिन डिफ़ॉल्ट रूप से बंद रहते हैं — यदि आप इन्हें चाहते हैं तो इन्हें जोड़ लें, जैसा कि नीचे बताया गया है।

## पैनल

बार के किसी आइकन पर क्लिक करने से एक पैनल खुलता है, जो tooltip के बजाय sliders, सूचियों और keyboard navigation वाला एक proper पॉपअप होता है। हर एक की एक hotkey भी होती है, इसलिए आपको कभी 16-pixel वाले glyph पर निशाना नहीं साधना पड़ता:

| Hotkey | पैनल |
| --- | --- |
| `Super + Ctrl + A` | ऑडियो |
| `Super + Ctrl + N` | नेटवर्क |
| `Super + Ctrl + B` | ब्लूटूथ |
| `Super + Ctrl + D` | डिस्प्ले |
| `Super + Ctrl + P` | पावर |
| `Super + Ctrl + Alt + D` | Calendar |
| `Super + Ctrl + Alt + E` | वर्ल्ड क्लॉक |
| `Super + Ctrl + X` | Agents |
| `Super + Ctrl + 1-9` | दाएँ खंड में n-वाँ पैनल टॉगल करें |

पैनल केवल जानकारी दिखाने के लिए नहीं हैं। यहीं आप असल में वह काम करते हैं:

- **Audio** में एक master वॉल्यूम slider, एक output-device picker और एक per-app mixer होता है, ताकि आप बाकी सब कुछ छुए बिना उस एक browser tab की आवाज़ कम कर सकें।
- **Network** Wi-Fi के लिए स्कैन करता है, signal strength दिखाता है, कनेक्ट करता है और आपको DNS provider चुनने देता है।
- **Bluetooth** आपके डिवाइसों को connect/disconnect और बैटरी स्तरों के साथ सूचीबद्ध करता है।
- **Power** बैटरी के आँकड़े दिखाता है, power profiles बदलता है (यह बैटरी और AC के लिए अलग-अलग पसंद याद रखता है), और कुछ system जानकारी प्रिंट करता है।
- **Display** में चमक slider, text आकार, मॉनिटर scaling presets और — जब आपके पास एक से अधिक स्क्रीन हो — per-monitor नियंत्रण होते हैं। गहरी जानकारी के लिए [मॉनिटर्स](33-monitors.md) देखें।
- **Clock** ISO सप्ताह संख्याओं और महीना आगे-पीछे करने की सुविधा के साथ एक महीने का grid खोलता है।
- **World clock** हर शहर के लिए एक पंक्ति रखता है, उसके मौसम और उसके दिन की प्रगति के साथ। Search कस्बों के साथ-साथ time zones भी खोजता है, इसलिए Fort Lauderdale, Fort Lauderdale ही है, New York नहीं। यदि ऊपर की पंक्ति गलत शहर का नाम बताती है, तो उस पर क्लिक करें और बताएँ कि आप कहाँ हैं; किसी अन्य time zone की जगह चुनें और system घड़ी भी वहाँ चली जाएगी, जो यात्रा के समय काम की बात है। किसी शहर पर होवर करें और व्यक्ति बटन पर क्लिक करके बताएँ कि वहाँ कौन रहता है — सादे नाम, या `@` GitHub handles ताकि उनके चेहरे भी साथ आ जाएँ।

हर पैनल mouse के साथ-साथ keyboard भी लेता है: तीर घूमते हैं, Return सक्रिय करता है, Tab पड़ोसी पैनल पर जाता है, और Escape बंद करता है।

`Super + Ctrl + 1-9` दाएँ खंड में पैनलों को बाएँ से दाएँ गिनता है, tray को छोड़कर क्योंकि उसका अपना कोई पैनल नहीं होता। इसलिए संख्या उसी आइकन से मेल खाती है जिसकी ओर आप इशारा करते।

### Tailscale और Dropbox

दो और विजेट बार पर केवल तभी दिखाई देते हैं जब आप **Install → Service** से मिलती-जुलती service इंस्टॉल करते हैं, और दोनों को जानना फ़ायदेमंद है क्योंकि वे केवल status बताने से अधिक करते हैं।

**Tailscale** पैनल tailnet को कनेक्ट और डिस्कनेक्ट करता है, खातों के बीच बदलता है, और एक exit node चुनता है (आपकी अपनी मशीनें और Mullvad क्षेत्र दोनों उस सूची में दिखाई देते हैं)। यह आपकी मशीनों को ब्राउज़ भी करता है — और किसी एक को चुने होने पर, `s` उसे Taildrop के ज़रिए फ़ाइलें भेजता है, जो किसी फ़ाइल को आपके फ़ोन या किसी अन्य laptop तक पहुँचाने का सबसे तेज़ तरीका है। `c` मशीन का IP कॉपी करता है, `n` उसका नाम, और `d` उसका पूरा DNS नाम। हर मशीन की पंक्ति पर एक send बटन भी होता है, यदि आप क्लिक करना पसंद करें। terminal से वही काम `omarchy tailscale send <machine> [file...]` है।

**Dropbox** पैनल login संभालता है, दिखाता है कि आपने कितना storage उपयोग किया है, और हाल में sync हुई फ़ाइलों को सूचीबद्ध करता है।

किसी भी service को हटाने से उसका विजेट बार से वापस हट जाता है।

## संकेतक

बीच का छोटा-सा समूह संकेतक विजेट है। ये उन modes के लिए status glyphs हैं जिन्हें आपने चालू किया है: do not disturb, night light, एक कतार में लगा [रिमाइंडर](09-reminders.md), एक सक्रिय स्क्रीन रिकॉर्डिंग, और stay awake, साथ ही तब चेतावनियाँ जब passwordless sudo चालू हो या कोई remote session से जुड़ा हो। ये तब चमकते हैं जब mode सक्रिय हो और अन्यथा रास्ते से दूर रहते हैं — उन पर झाँकने के लिए उनके ठीक बगल में होवर करें, जहाँ निष्क्रिय वाले बैठे होते। किसी संकेतक पर क्लिक करने से वह mode टॉगल हो जाता है। एक और केवल status के लिए है: एक remote session लाल रंग में चमकता है जब कोई gliff के ज़रिए इस मशीन से जुड़ा होता है।

यदि आप चाहते हैं कि वे हमेशा दिखाई दें, तो विजेट पर `alwaysShow` को `true` पर सेट करें। और यदि आपको केवल उनमें से कुछ की परवाह है, तो जिन्हें आप चाहते हैं उन्हें `items` में सूचीबद्ध करें: `["Dnd", "Reminder", "NightLight"]`। आपके पास एक से अधिक संकेतक विजेट हो सकते हैं, इसलिए अलग-अलग खंड अलग-अलग उपसमूह दिखा सकते हैं।

## बार को पुनर्व्यवस्थित करना

बार खुद को कॉन्फ़िगर करता है। चीज़ों को हटाने के लिए आपको कोई config फ़ाइल नहीं खोलनी पड़ती।

बार के बीच के आसपास के खाली हिस्से को पकड़ें और उसे स्क्रीन के किसी अन्य किनारे की ओर खींचें, और बार वहाँ चला जाता है — बाएँ, दाएँ, ऊपर या नीचे, सब काम करता है, और हर विजेट अनुकूल हो जाता है (ऊर्ध्वाधर बार संक्षिप्त, केवल-आइकन रूपों पर वापस आ जाते हैं)। क्लिक करके पकड़े रखना वही खींचना शुरू करता है। उसी खाली जगह पर डबल-बायाँ-क्लिक करके बार की पृष्ठभूमि को clear से glassy से opaque तक बदलें। और किसी भी विजेट को खींचकर उसे पुनः क्रमित करें या किसी अन्य खंड में फेंक दें; अन्य विजेट वहाँ जगह बनाने के लिए अलग-अलग खिसक जाते हैं जहाँ वह उतरेगा।

बार का मध्य एक box है: जो कुछ इसमें होता है वह एक समूह के रूप में केंद्रित रहता है, और इसके दोनों ओर के विजेट इसके किनारों से लटके रहते हैं। जब आप किसी विजेट को खींचते हैं तो box एक रूपरेखा के रूप में दिखाई देता है, या जब यह खाली हो तो बार के आर-पार एक रेखा के रूप में, और आप इसमें या इसके बगल में छोड़ सकते हैं। जब कोई drop box में उतरने वाला होता है, तो box विजेट को लेने के लिए बढ़ जाता है।

जिस विजेट को आप आसपास चाहते हैं लेकिन हमेशा दृष्टि में नहीं, वह tray की दराज़ में जा सकता है: उसे tray पर खींचें, और दराज़ उसे लेने के लिए खुल जाती है। यह वहाँ app आइकनों के बाद बैठता है, जब भी दराज़ दिखाई देती है तब दिखाई देता है, और जब उसका पैनल खुला हो तो अपनी दराज़ को खुला रखता है। उसे वापस बार पर खींचकर वापस रख दें।

यदि आप menu से चुनना पसंद करते हैं, तो **Appearance → Menu Bar** में स्थिति है, और **Bar Background** चुनता है कि बार कैसे बनाया जाए: **Opaque Bar**, **Glassy Bar** (पारदर्शी, उसके पीछे जो है वह धुंधला हुआ), या **Clear Bar**।

उन्हीं चीज़ों के commands भी हैं, जो आप [dotfiles](31-dotfiles.md) setup के लिए चाहते हैं:

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

किसी विजेट को पूरी तरह जोड़ने या हटाने के लिए, plugin commands का उपयोग करें। `omarchy plugin list` shell को ज्ञात हर विजेट को उसके id के साथ प्रिंट करता है, और फिर:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## बार को छिपाना

`Super + Shift + Space` shell को मारे बिना बार को बंद और वापस चालू करता है — पैनल और hotkeys काम करते रहते हैं, बस आपको pixels वापस मिल जाते हैं। यह menu में **Appearance → Menu Bar → Hide Bar** के अंतर्गत भी है।

## config फ़ाइल

यह सब `~/.config/omarchy/shell.json` में, `bar` key के अंतर्गत संग्रहीत होता है। यहाँ एक संक्षिप्त संस्करण है:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

हर विजेट पाँच layout arrays में से किसी एक में एक प्रविष्टि होता है, और उसकी settings उसी प्रविष्टि पर inline बैठती हैं — कोई अलग settings फ़ाइल नहीं होती और कोई `config` sub-object नहीं होता। घड़ी का `format`, `formatAlt` (जिस पर दायाँ क्लिक बदलता है), और `verticalFormat` सब वहीं `{ "id": "omarchy.clock" }` पर रहते हैं।

`center` बार के बीच का box है: इसमें सब कुछ स्क्रीन पर एक समूह के रूप में केंद्रित होता है। `centerBegin` और `centerEnd` box के दोनों ओर लटके रहते हैं, जिससे घड़ी ठीक बीच में रहती है, भले ही मौसम और अपडेट बैज आते-जाते रहें। `center` में एक से अधिक विजेट रखें और वे एक साथ केंद्रित होते हैं; इसे खाली छोड़ दें और `centerBegin` और `centerEnd` बार के बीच में मिल जाते हैं।

एक नियम जिसे आत्मसात करना फ़ायदेमंद है: **एक बार जब आपके पास अपना `shell.json` हो, तो वही आधिकारिक होता है**। जब तक आप कुछ भी अनुकूलित नहीं करते, shell Omarchy की डिफ़ॉल्ट फ़ाइल पढ़ता है। जिस क्षण आप कोई विजेट खींचते हैं, `omarchy bar` चलाते हैं, या फ़ाइल को खुद संपादित करते हैं, आप उसके मालिक बन जाते हैं — कोई deep merge नहीं होता, इसलिए भविष्य के Omarchy releases में नए डिफ़ॉल्ट विजेट आपकी बार पर अपने आप नहीं दिखाई देंगे। `omarchy bar defaults` जब भी आप एक साफ़ शुरुआत चाहते हैं, भेजा गया layout वापस रख देता है।

वही फ़ाइल शीर्ष स्तर पर, `bar` key के बाहर, आपके idle timings भी रखती है: `idle.screensaver` और `idle.lock`, दोनों आपके idle होने के बाद के सेकंडों में। इसलिए डिफ़ॉल्ट screensaver 150 सेकंड पर शुरू होता है और lock 300 पर।
