# הסרגל העליון

הרצועה לאורך החלק העליון של המסך היא סרגל Omarchy. זה לא סרגל סטטוס שמצמידים מבחוץ, אלא חלק ממעטפת Omarchy, אותו תהליך Quickshell יחיד וארוך־חיים שגם מצייר את התפריט, את ההתראות, את חלוניות ה־OSD ואת מסך הנעילה. לכן הוא מתאים בצורה מושלמת לכל השאר, ולכן פאנל נפתח מיד במקום להפעיל אפליקציה חדשה.

זה גם החלק היחיד של שולחן העבודה שנשאר תמיד על המסך, אז כדאי לדעת מה עושים כל הגליפים הקטנים האלה.

## מה יש עליו כברירת מחדל

לסרגל יש שלושה מקטעים. בצד שמאל יושב לוגו Omarchy (מפעיל התפריט) ומחווני סביבות העבודה. במרכז יש את מחווני הסטטוס, השעון, Elsewhen (שעון עולמי), מזג האוויר ותג עדכון של Omarchy. בצד ימין: מגש המערכת, פריסת המקלדת (כאשר מוגדרת יותר מפריסה אחת או שיטת קלט אחת), סוכנים, Bluetooth, רשת, שמע, תצוגה וחשמל.

כמה מהם מופיעים רק כשיש להם מה לומר. פריסת המקלדת מופיעה רק אם הגדרת יותר מפריסה אחת או שיטת קלט אחת. תג העדכון מופיע רק כאשר ממתין עדכון ל־Omarchy.

## ללחוץ מסביב

כמעט כל רכיב עושה משהו בלחיצה שמאלית, ימנית ואמצעית, וכמה מהם מגיבים גם לגלילה. זה החלק שאנשים מפספסים — הכפתורים הימני והאמצעי הם המקום שבו מסתתרים הרבה מהדברים הטובים.

| רכיב | שמאלי | ימני | אמצעי / גלילה |
| --- | --- | --- | --- |
| תפריט | תפריט Omarchy | מסוף חדש | — |
| סביבות עבודה | מיקוד סביבת העבודה הזו במסך זה | — | גלילה: סביבת העבודה הבאה/הקודמת |
| שעון | חלונית לוח שנה | מעבר מחזורי בין פורמטי התווית | אמצעי: בורר אזור זמן |
| שעון עולמי | פאנל שעון עולמי | רענון | אמצעי: רענון |
| מזג אוויר | חלונית תחזית | מזג אוויר מלא כהתראה | אמצעי: רענון |
| שמע | פאנל שמע | השתקה | אמצעי: פאנל · גלילה: עוצמת קול |
| מיקרופון | השתקת המיקרופון | — | אמצעי: פאנל שמע · גלילה: עוצמת קלט |
| רשת | פאנל רשת | — | — |
| Bluetooth | פאנל Bluetooth | הפעלה/כיבוי של הרדיו | — |
| תצוגה | פאנל תצוגה | — | גלילה: בהירות |
| חשמל | פאנל חשמל | הצגה/הסתרה של אחוזי הסוללה | — |

לא כל מה שבטבלה הזו נמצא על הסרגל שלך מהקופסה. רכיב המדיה (MPRIS שמנגן עכשיו, עם שיר ואמן שגוללים) ורכיב המיקרופון שניהם מובנים אבל כבויים כברירת מחדל — הוסף אותם אם אתה רוצה אותם, כפי שמתואר למטה.

## הפאנלים

לחיצה על סמל בסרגל פותחת פאנל, שהוא חלונית אמיתית עם מחוונים, רשימות וניווט במקלדת, ולא טולטיפ. לכל אחד יש גם קיצור מקלדת, כך שלעולם לא צריך לכוון לגליף של 16 פיקסלים:

| קיצור מקלדת | פאנל |
| --- | --- |
| `Super + Ctrl + A` | שמע |
| `Super + Ctrl + N` | רשת |
| `Super + Ctrl + B` | Bluetooth |
| `Super + Ctrl + D` | תצוגה |
| `Super + Ctrl + P` | חשמל |
| `Super + Ctrl + Alt + D` | לוח שנה |
| `Super + Ctrl + Alt + E` | שעון עולמי |
| `Super + Ctrl + X` | סוכנים |
| `Super + Ctrl + 1-9` | הפעלה/כיבוי של הפאנל ה־n במקטע הימני |

הפאנלים הם לא רק תצוגות. שם באמת עושים את הדבר:

- **שמע** כולל מחוון עוצמת קול ראשי, בורר התקן פלט ומיקסר לפי אפליקציה, כך שאפשר להנמיך את לשונית הדפדפן האחת הזו בלי לגעת בכל השאר.
- **רשת** סורקת רשתות Wi-Fi, מציגה עוצמת אות, מתחברת ומאפשרת לבחור ספק DNS.
- **Bluetooth** מציגה את ההתקנים שלך עם חיבור/ניתוק ורמות סוללה.
- **חשמל** מציג נתוני סוללה, מחליף פרופילי חשמל (הוא זוכר בחירה נפרדת לסוללה ולחשמל AC), ומציג קצת מידע על המערכת.
- **תצוגה** כוללת מחוון בהירות, גודל טקסט, קביעות מראש של קנה מידה למסכים, ו — כאשר יש יותר ממסך אחד — פקדים לכל מסך בנפרד. ראה [מסכים](33-monitors.md) לסיפור העמוק יותר.
- **שעון** פותח רשת חודשית עם מספרי שבועות לפי ISO ומעבר בין חודשים.
- **שעון עולמי** שומר שורה לכל עיר, עם מזג האוויר שלה ואיך הולך הולך לה היום. החיפוש מוצא גם עיירות וגם אזורי זמן, כך ש־Fort Lauderdale היא Fort Lauderdale ולא New York. אם השורה למעלה מציינת את העיר הלא נכונה, לחץ עליה ואמור איפה אתה נמצא; בחר מקום באזור זמן אחר ושעון המערכת יעבור לשם גם הוא, מה ששימושי כשנוסעים. רחף מעל עיר ולחץ על כפתור האדם כדי לומר מי גר שם — שמות רגילים, או מזהי GitHub עם `@` כדי להביא איתם גם את הפרצופים שלהם.

כל פאנל מקבל גם את המקלדת וגם את העכבר: החצים זזים, Return מפעיל, Tab עובר לפאנל השכן, ו־Escape סוגר.

`Super + Ctrl + 1-9` סופר פאנלים משמאל לימין במקטע הימני, ומדלג על המגש כי אין לו פאנל משלו. כך המספר מתאים לסמל שהיית מצביע עליו.

### Tailscale ו־Dropbox

שני רכיבים נוספים מופיעים על הסרגל רק אחרי שמתקינים את השירות המתאים מתוך **התקנה → שירות**, ושניהם שווים היכרות כי הם עושים יותר מלדווח על סטטוס.

פאנל **Tailscale** מחבר ומנתק את ה־tailnet, מחליף בין חשבונות ובוחר צומת יציאה (המכונות שלך וגם אזורי Mullvad מופיעים ברשימה הזו). הוא גם מעיין במכונות שלך — וכאשר אחת נבחרה, `s` שולח אליה קבצים דרך Taildrop, שזו הדרך המהירה ביותר להעביר קובץ לטלפון שלך או למחשב נייד אחר. `c` מעתיק את ה־IP של המכונה, `n` את שמה, ו־`d` את שם ה־DNS המלא שלה. יש גם כפתור שליחה בכל שורת מכונה, אם אתה מעדיף ללחוץ. אותו דבר מהמסוף הוא `omarchy tailscale send <machine> [file...]`.

פאנל **Dropbox** מטפל בהתחברות, מציג כמה נפח אחסון ניצלת ומציג קבצים שסונכרנו לאחרונה.

הסרת כל אחד מהשירותים מורידה גם את הרכיב שלו מהסרגל.

## מחוונים

האשכול הקטן במרכז הוא רכיב המחוונים. אלה גליפי סטטוס למצבים שהפעלת: נא לא להפריע, תאורת לילה, [תזכורת](09-reminders.md) שממתינה בתור, הקלטת מסך פעילה והישארות ערה, ובנוסף אזהרות בזמן ש־sudo ללא סיסמה מופעל או שמישהו מחובר להפעלה מרוחקת. הם נדלקים כשהמצב פעיל ואחרת נשארים בצד — רחף ממש לידם, במקום שבו היו יושבים אלה שלא פעילים, כדי להציץ בהם. לחיצה על מחוון מפעילה או מכבה את המצב הזה. אחד נוסף הוא לסטטוס בלבד: הפעלה מרוחקת נדלקת באדום בזמן שמישהו מחובר למכונה הזו דרך gliff.

אם אתה מעדיף שהם יהיו תמיד גלויים, הגדר את `alwaysShow` ל־`true` ברכיב. ואם אכפת לך רק מחלק מהם, רשום את אלה שאתה רוצה ב־`items`: `["Dnd", "Reminder", "NightLight"]`. אפשר שיהיה יותר מרכיב מחוונים אחד, כך שמקטעים שונים יכולים להציג תתי־קבוצות שונות.

## סידור מחדש של הסרגל

הסרגל מגדיר את עצמו. לא צריך לפתוח קובץ תצורה כדי להזיז דברים.

תפוס פיסת סרגל ריקה סביב המרכז וגרור אותה לעבר קצה אחר של המסך, והסרגל יעבור לשם — שמאל, ימין, למעלה או למטה, הכל עובד, וכל רכיב מתאים את עצמו (סרגלים אנכיים חוזרים לצורות קומפקטיות של סמלים בלבד). לחיצה והחזקה מתחילה את אותה גרירה. לחיצה שמאלית כפולה על אותו שטח ריק תעביר מחזורית את רקע הסרגל משקוף לזכוכיתי לאטום. וגרור כל רכיב כדי לסדר אותו מחדש או לזרוק אותו למקטע אחר; שאר הרכיבים גולשים הצידה כדי לפנות מקום במקום שבו הוא ינחת.

אמצע הסרגל הוא תיבה: כל מה שבתוכה נשאר ממורכז כקבוצה אחת, והרכיבים משני צדיה תלויים על קצותיה. בזמן שגוררים רכיב התיבה מופיעה כקו מתאר, או כקו לרוחב הסרגל כשהיא ריקה, ואפשר להפיל לתוכה או לצידה. כאשר הפלה אמורה לנחות בתיבה, התיבה גדלה כדי לקלוט את הרכיב.

רכיב שרוצים שיהיה בסביבה אבל לא תמיד גלוי יכול להיכנס למגירת המגש: גרור אותו אל המגש, והמגירה תיפתח כדי לקבל אותו. הוא יושב שם אחרי סמלי האפליקציות, מופיע בכל פעם שהמגירה מופיעה, ושומר את המגירה שלו פתוחה בזמן שהפאנל שלו למעלה. גרור אותו בחזרה החוצה אל הסרגל כדי להחזיר אותו.

אם אתה מעדיף לבחור מתפריט, ב־**מראה → סרגל תפריטים** נמצא המיקום, ו־**רקע הסרגל** בוחר איך הסרגל מצויר: **סרגל אטום**, **סרגל זכוכיתי** (שקוף, עם טשטוש של מה שמאחוריו), או **סרגל שקוף**.

לאותם דברים יש גם פקודות, וזה מה שרוצים בשביל התקנת [dotfiles](31-dotfiles.md):

```bash
omarchy bar position bottom
omarchy bar background glassy  # opaque, glassy, none, or cycle
omarchy bar move omarchy.weather --section centerBegin --index 0
omarchy bar move omarchy.bluetooth --section tray  # into the tray's drawer
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout
```

כדי להוסיף או להסיר רכיב לגמרי, השתמש בפקודות התוספים. `omarchy plugin list` מדפיסה כל רכיב שהמעטפת מכירה עם המזהה שלו, ואז:

```bash
omarchy plugin enable omarchy.media --section centerEnd
omarchy plugin disable omarchy.weather
```

## הסתרת הסרגל

`Super + Shift + Space` מכבה את הסרגל ומדליק אותו בחזרה בלי להרוג את המעטפת — הפאנלים וקיצורי המקלדת ממשיכים לעבוד, אתה פשוט מקבל את הפיקסלים בחזרה. זה נמצא גם בתפריט תחת **מראה → סרגל תפריטים → הסתרת הסרגל**.

## קובץ התצורה

כל זה נשמר ב־`~/.config/omarchy/shell.json`, תחת מפתח `bar`. הנה גרסה מצומצמת:

```json
{
  "version": 1,
  "bar": {
    "position": "top",
    "background": "none",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "centerBegin": [{ "id": "omarchy.indicators" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "centerEnd": [{ "id": "omarchy.weather" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}
```

כל רכיב הוא רשומה אחת באחד מחמשת מערכי הפריסה, וההגדרות שלו יושבות בתוך אותה רשומה — אין קובץ הגדרות נפרד ואין תת־אובייקט `config`. ה־`format`, ה־`formatAlt` (מה שלחיצה ימנית עוברת אליו מחזורית) וה־`verticalFormat` של השעון כולם חיים ממש שם על `{ "id": "omarchy.clock" }`.

`center` היא התיבה באמצע הסרגל: כל מה שבתוכה ממורכז על המסך כקבוצה אחת. `centerBegin` ו־`centerEnd` תלויים משני צדי התיבה, וכך השעון נשאר במרכז המדויק גם כשמזג האוויר ותג העדכון באים והולכים. שים יותר מרכיב אחד ב־`center` והם ימְמוּרכזו יחד; השאר אותה ריקה ו־`centerBegin` ו־`centerEnd` ייפגשו באמצע הסרגל.

כלל אחד שכדאי להפנים: **מרגע שיש לך `shell.json` משלך, הוא הקובע**. עד שאתה מתאים אישית משהו, המעטפת קוראת את קובץ ברירת המחדל של Omarchy. ברגע שאתה גורר רכיב, מפעיל `omarchy bar`, או עורך את הקובץ בעצמך, הוא שלך — אין מיזוג עמוק, כך שרכיבי ברירת מחדל חדשים במהדורות Omarchy עתידיות לא יופיעו על הסרגל שלך אוטומטית. `omarchy bar defaults` מחזיר את הפריסה שסופקה בכל פעם שאתה רוצה לוח נקי.

אותו קובץ מחזיק גם את תזמוני חוסר הפעילות שלך ברמה העליונה, מחוץ למפתח `bar`: `idle.screensaver` ו־`idle.lock`, שניהם בשניות מאז שהפסקת להיות פעיל. כך שומר המסך המוגדר כברירת מחדל נכנס לפעולה אחרי 150 שניות והנעילה אחרי 300.
